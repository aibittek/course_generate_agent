源码反向同步工作流

Source Code → CSV → Downstream Docs 闭环同步架构

源码能力提取

  • • 解析 import 语句 → tech_stack
  • • 统计代码行数 → hours 估算
  • • 提取 docstring → name 候选
  • • 检测算法复杂度 → difficulty

CSV 更新建议

  • • 字段级对比（old vs new）
  • • 置信度评估（0.0 - 1.0）
  • • 级联影响提示（cascade_impact）
  • • YAML 格式输出供人工审查

增量同步机制

  • • 字段级粒度：仅改 hours 不重跑源码分析
  • • 定向回放：避免全流程重做
  • • 自动触发：CSV 变更 → 下游同步
  • • 预计耗时：5-15 分钟 vs 全量 30-60 分钟
