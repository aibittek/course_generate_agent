# 机器人ROS2应用与开发 教学大纲

> 课程代码: EXP003
> 适用对象: 本科三年级 / 高职二年级 机器人工程、人工智能、自动化相关专业
> 总学时: 48h（理论0h + 实验48h）
> 课程类型: 专业核心实践课
> 硬件平台: 具身智能实验箱B2 / 具身智能机器人小车C1
> 制定日期: 2026-08-10

---

## 一、课程目标

### 1.1 知识目标

通过本课程的学习，学生能够：

1. 掌握ROS2分布式机器人操作系统的核心架构，理解DDS去中心化通信模型下节点、话题、服务、动作四类通信机制的语义边界与适用场景
2. 理解ROS2节点生命周期管理、工作空间层级叠加(Underlay/Overlay)机制、colcon编译系统以及功能包依赖管理的设计原理
3. 了解TF2坐标变换树的数学基础与时间戳插值机制、URDF/Xacro机器人建模规范以及Gazebo物理仿真的参数体系

### 1.2 能力目标

通过本课程的学习，学生能够：

1. 具备在B2实验箱/C1机器人小车平台独立搭建ROS2开发环境、创建功能包并完成编译部署的能力
2. 能够独立完成基于话题/服务/动作通信的传感器驱动节点开发，将MQ5气体传感器(ADC)、MFRC522读卡器(SPI)、指纹传感器(UART)等硬件封装为标准ROS2 Node
3. 能够运用Launch文件、Rqt工具箱、ros2 bag录制回放、Rviz2可视化等工具链进行多节点系统调试与离线数据分析
4. 能够使用TF2坐标变换、URDF/Xacro建模和Gazebo仿真搭建完整的机器人仿真验证环境

### 1.3 素养目标

通过本课程的学习，学生能够：

1. 养成"先仿真验证、后实机部署"的安全工程意识，形成模块化、松耦合的分布式系统开发方法论
2. 具备基于标准接口协作开发的团队意识，理解接口先行、契约优先的分工方式
3. 树立对ROS2开源社区规范（REP命名约定、坐标系标准、消息接口设计原则）的遵循意识

## 三、教学内容

### 第1章 ROS2基础与环境搭建

> 学时: 10h | 实验项目: exp01~exp04, exp18 | 技术栈: ROS2

#### 教学内容

- ROS2概述与架构：发展背景、设计目标、与ROS1的核心区别（去Master化DDS通信架构 vs TCPROS主从架构、colcon vs catkin编译系统）
- ROS2命令行工具集：ros2 node/topic/service/param/interface/bag六大子命令组的系统化使用与自省操作
- ROS2工作空间：src/build/install/log四层目录结构、colcon build编译流程、Underlay(/opt/ros/humble)与Overlay层级叠加机制、环境加载
- ROS2功能包管理：package.xml元信息与依赖声明(build_depend/exec_depend)、ament_python与ament_cmake构建类型、setup.py/setup.cfg配置
- ROS2元功能包：概念定义与作用、典型应用场景(ros2_desktop/navigation2)、通过exec_depend聚合相关功能包的组织方式

#### 重点难点

- **重点**: ROS2去中心化架构的理解、工作空间创建编译与加载的标准流程、CLI工具的熟练使用
- **难点**: Underlay/Overlay层级叠加导致的"改了代码不生效"排查、build_depend与exec_depend的区别与正确配置

#### 教学活动

- [x] 理论讲授（实验前概述，融合在实验引导环节中）
- [x] 动手实验（5个实验，每实验2h）
- [x] 案例分析（ros2 run demo_nodes_cpp talker/listener验证节点通信）

#### 对应知识点

1.1.1~1.1.3 ROS2概述与架构 · 1.2.1~1.2.3 ROS2命令行工具 · 1.3.1~1.3.3 ROS2工作空间 · 1.4.1~1.4.3 ROS2功能包管理

### 第2章 ROS2核心通信机制

> 学时: 18h | 实验项目: exp05~exp10 | 技术栈: ROS2

#### 教学内容

- ROS2节点编程：继承rclpy.node.Node创建自定义节点类、节点生命周期(构造→spin→destroy)、传感器硬件(ADC/SPI/UART)在构造函数中的初始化模式
- 话题通信：发布者/订阅者异步一对多模型、create_publisher/create_subscription编程流程、DDS全局数据空间的消息分发机制、MQ5气体传感器ADC模拟量采集与ppm浓度换算的完整实战
- 服务通信：客户端/服务器同步RPC一对一模型、create_service注册回调与同步call请求、指纹传感器UART串口通信与VerifyFingerprint服务定义实现
- 动作通信：Goal-Feedback-Result异步三通道长耗时任务模型、ActionServer三回调(goal/feedback/cancel)实现、MFRC522读卡器SPI接口的刷卡检测异步动作任务
- 自定义接口消息：ros_sensor_interfaces接口包设计、.msg/.srv/.action的IDL语法定义、CMakeLists.txt中rosidl_generate_interfaces编译配置
- 参数服务：declare_parameter声明参数与默认值、get/set运行时读写、add_on_set_parameters_callback动态回调、ParameterDescriptor参数范围限制

#### 重点难点

- **重点**: 三种通信范式(话题/服务/动作)的语义边界与编程实现、传感器节点封装的标准模式、自定义消息接口的完整编译链路
- **难点**: 动作通信中异步状态机的设计、服务同步调用在回调内的死锁风险、参数动态回调的线程安全、接口包必须使用ament_cmake构建类型

#### 教学活动

- [x] 理论讲授（实验前概述，融合在实验引导环节中）
- [x] 动手实验（6个实验，共计18h）
- [x] 案例分析（三种传感器节点分别展示话题/服务/动作三种通信范式的典型应用）

#### 对应知识点

2.1.1~2.1.3 ROS2节点编程 · 2.2.1~2.2.4 话题通信 · 2.3.1~2.3.3 服务通信 · 2.4.1~2.4.3 动作通信 · 2.5.1~2.5.4 通信接口与参数系统

### 第3章 ROS2底层机制与分布式通信

> 学时: 6h | 实验项目: exp11~exp13 | 技术栈: ROS2, DDS

#### 教学内容

- ROS2时间系统：builtin_interfaces/Time时间类型(秒+纳秒)、get_clock().now()获取当前时间、create_timer(period, callback)创建周期性定时器、use_sim_time仿真时间同步机制
- DDS通信中间件：RMW(ROS Middleware)抽象层架构与DDS实现可切换(Fast-DDS/CycloneDDS)、RTPS协议层次(Participant→Endpoint→Writer/Reader)、Simple Discovery Protocol自动发现机制(SPDP参与者发现+SEDP端点发现)、QoS策略配置(Reliability/Best Effort, Durability, History Depth)
- 分布式通信：ROS_DOMAIN_ID(0-232)通信域隔离、多机通信前提条件(同网段+同Domain ID)、ROS_DISCOVERY_SERVER中心化发现方案、DDS-Security加密通信(governance+permissions文件)

#### 重点难点

- **重点**: 时间戳在传感器消息Header中的实际应用、QoS策略的场景化选型与配置、局域网多机通信实操
- **难点**: DDS自动发现两阶段协议(SPDP+SEDP)的通信流程理解、仿真时间与系统时钟的切换时机与影响

#### 教学活动

- [x] 理论讲授（实验前概述，融合在实验引导环节中）
- [x] 动手实验（3个实验，每实验2h）
- [x] 小组讨论（分布式通信域隔离与DDS-Security安全配置的工程实践方案）

#### 对应知识点

3.2.1~3.2.3 时间系统 · 3.1.1~3.1.4 DDS通信中间件 · 3.3.1~3.3.3 分布式通信

### 第4章 ROS2工具链与系统部署

> 学时: 8h | 实验项目: exp14~exp17 | 技术栈: ROS2, Launch, Rviz2

#### 教学内容

- Rqt调试工具箱：rqt_graph节点-话题-服务拓扑可视化、rqt_plot实时话题数据曲线绘制、rqt_console日志级别过滤(DEBUG/INFO/WARN/ERROR)、rqt_reconfigure动态参数调整界面
- Rviz2三维可视化：基于OGRE的Display插件体系(RobotModel/TF/LaserScan/PointCloud2/Image/Path/Marker)、Fixed Frame固定参考坐标系配置、.rviz配置文件保存加载实现调试环境快速复现
- 数据录制与回放：ros2 bag record -a全量录制与-t指定话题选择性录制、ros2 bag info查看包元数据(话题数/消息数/时长)、ros2 bag play调速回放、结合Rviz2离线可视化分析
- Launch启动管理：Python Launch文件(Node声明/参数配置/remap重映射)、节点启动顺序与依赖管理、IfCondition/UnlessCondition条件启动、OnProcessExit事件触发、LaunchArgument参数化复用

#### 重点难点

- **重点**: Rviz2多种Display面板的配置与话题关联方法、Launch文件的多节点编排与参数传递、ros2 bag与Rviz2的联合离线分析
- **难点**: Launch节点的条件启动与事件触发逻辑的调试、Rviz2中坐标系不匹配导致的数据不显示问题排查

#### 教学活动

- [x] 理论讲授（实验前概述，融合在实验引导环节中）
- [x] 动手实验（4个实验，每实验2h）
- [x] 案例分析（使用Rqt定位ROS2系统通信异常、Launch一键启动传感器全链路系统）

#### 对应知识点

4.1.1~4.1.3 Rqt调试工具箱 · 4.2.1~4.2.3 Rviz2三维可视化 · 4.3.1~4.3.3 数据录制与回放 · 4.4.1~4.4.3 Launch启动管理

### 第5章 机器人建模与仿真

> 学时: 6h | 实验项目: exp19~exp21 | 技术栈: TF2, URDF, Xacro, Gazebo

#### 教学内容

- TF2坐标变换：树形结构管理多坐标系父子关系、StaticTransformBroadcaster发布静态变换、TransformBroadcaster定时发布动态变换、Buffer+TransformListener查询任意两个frame间的相对位姿、tf2_echo/view_frames工具可视化TF树
- URDF机器人建模：XML描述机器人结构、link定义(visual视觉/collision碰撞/inertial惯性属性)、joint定义(旋转/固定/移动/连续类型与原点和轴和限位约束)、Xacro宏语言(宏定义/数学表达式/文件include)简化复杂模型描述
- Gazebo物理仿真：集成ODE/Bullet物理引擎的3D仿真平台、World文件结构与URDF模型导入、gazebo_ros2_control插件实现ROS2控制接口、虚拟传感器(激光雷达/深度相机/IMU)插件配置与数据自动发布

#### 重点难点

- **重点**: TF2坐标变换树的构建与lookup_transform查询的方法、URDF运动学模型的完整编写流程、Gazebo仿真环境搭建与传感器数据验证
- **难点**: Xacro宏语言参数化建模的设计思路、Gazebo物理引擎参数(质量/惯性/碰撞/摩擦)调优、多传感器仿真插件的数据时间戳同步

#### 教学活动

- [x] 理论讲授（实验前概述，融合在实验引导环节中）
- [x] 动手实验（3个实验，每实验2h）
- [x] 项目实战（搭建包含URDF模型+Gazebo仿真+Rviz2可视化的完整机器人验证环境）

#### 对应知识点

5.1.1~5.1.3 TF2坐标变换 · 5.2.1~5.2.3 URDF机器人建模 · 5.3.1~5.3.3 Gazebo物理仿真
