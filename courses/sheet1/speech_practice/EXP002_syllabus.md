## 一、课程目标

### 1.1 知识目标
通过本课程的学习，学生能够：
1. 掌握基于 sherpa-onnx 的边缘侧语音处理栈（KWS/ASR/TTS）的部署与配置方法
2. 理解 ASR、TTS、VAD 的基本原理与端到端对话系统的状态机设计
3. 了解大模型 Function Calling 与多模态 VLM 在机器人交互中的工作原理
4. 熟悉 ROS2 节点化封装、YAML 参数化与 Launch 一键启动的开发模式

### 1.2 能力目标
通过本课程的学习，学生能够：
1. 具备在 B2/C1 平台上独立部署并调优本地语音模型的能力
2. 能够基于状态机构建 KWS+ASR+LLM(streaming)+TTS 端到端语音对话系统
3. 能够基于 RKLLM 部署 Function Calling 工具调用与多模态 VLM 推理
4. 能够运用 ROS2 通信机制实现多节点语音交互链路，处理打断、超时与多轮上下文

### 1.3 素养目标
通过本课程的学习，学生能够：
1. 养成离线优先、隐私敏感、低延迟的工程设计意识
2. 具备多模块协作的团队开发精神（语音/对话/大模型三方集成）
3. 树立对模型量化、NPU 部署、显存管理等资源约束的工程伦理意识

## 三、教学内容

### 第1章 语音唤醒 KWS

#### 教学内容
- KWS（Keyword Spotting）的概念与应用场景
- Zipformer-3M 编码器原理与轻量化优势
- keywords-file 关键词配置与中英文混合 token
- sensitivity 调参与误唤醒抑制

#### 重点难点
- **重点**: 基于 KeywordSpotter 实现离线唤醒
- **难点**: 误唤醒抑制策略（连续 N 帧、最短间隔、二次确认）

#### 教学活动
- [x] 演示：sherpa-onnx KWS 实时唤醒效果
- [x] 动手实验：exp02 语音唤醒

#### 对应知识点
2.1.1 KWS 概念 / 2.1.2 Zipformer-3M 原理 / 2.1.3 sherpa-onnx KWS 3MB / 2.2.1 keywords-file / 2.2.2 sensitivity 调参 / 2.2.3 tokens.txt / 2.3.1 连续 N 帧 / 2.3.2 最短触发间隔 / 2.3.3 二次确认

---

### 第2章 语音识别 ASR

#### 教学内容
- ASR 流水线（音频→重采样→特征→声学模型→语言模型→解码）
- FBank/MFCC 特征与 16kHz 单声道输入
- Online vs Offline Recognizer 的取舍
- VAD 端点检测与 vad_timeout_sec 调参
- WER（词错误率）评估方法

#### 重点难点
- **重点**: 本地 STT 部署与 WER < 10% 评估
- **难点**: VAD 超时参数在长句与响应速度间的平衡

#### 教学活动
- [x] 演示：100 条常用指令语料的 WER 评估
- [x] 动手实验：exp03 本地语音识别(ASR)

#### 对应知识点
3.1.1 ASR 流水线 / 3.1.2 FBank/MFCC 特征 / 3.1.3 Online vs Offline / 3.2.1 VAD 概念 / 3.2.2 vad_timeout_sec / 3.2.3 超时参数 3.0s / 3.3.1 WER 定义 / 3.3.2 100 条语料评估 / 3.3.3 S/D/I 错误拆解

---

### 第3章 语音合成 TTS

#### 教学内容
- TTS 原理（文本分析→韵律→声学模型→声码器）
- 主流 TTS 引擎对比（pyttsx3 / edge-tts / 讯飞）
- voice/speed/volume/pitch 参数调控
- /tts/stop 打断服务与多语种切换

#### 重点难点
- **重点**: 本地 TTS 部署与参数调优
- **难点**: 打断机制的事件信号与播放线程协作退出

#### 教学活动
- [x] 演示：不同 voice/speed/pitch 下的合成效果对比
- [x] 动手实验：exp04 本地 TTS 引擎与参数调控

#### 对应知识点
4.1.1 TTS 概念 / 4.1.2 端到端原理 / 4.1.3 pyttsx3/edge-tts/iflytek / 4.2.1 voice 切换 / 4.2.2 speed/volume/pitch 0-100 / 4.2.3 默认参数 50/80/50 / 4.3.1 /tts/stop 服务 / 4.3.2 打断机制原理 / 4.3.3 多语种切换

---

### 第4章 端到端对话与大模型集成

#### 教学内容
- 状态机式语音交互（IDLE/LISTENING/SPEAKING）
- Capture 线程常驻与 audio_queue 缓冲
- OpenAI 兼容 HTTP API 与流式 SSE
- RKLLM 本地推理引擎
- Function Calling 工具调用与三步注册
- 多模态大模型 VLM 原理
- RKLLM_INPUT_MULTIMODAL 接口
- 多模态交互闭环（ASR→VLM→TTS）

#### 重点难点
- **重点**: 端到端语音对话系统集成 + Function Calling + VLM
- **难点**: 流式响应按句分割送 TTS + 多模态 < 3s 延迟控制

#### 教学活动
- [x] 项目实战：exp05 端到端语音对话交互
- [x] 项目实战：exp06 Function Calling 工具调用

#### 对应知识点
