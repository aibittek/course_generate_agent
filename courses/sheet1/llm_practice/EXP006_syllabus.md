## 一、课程目标

### 1.1 知识目标
通过本课程的学习，学生能够：
1. 掌握具身智能工厂(装货/分拣/码垛/安全生产)综合项目的 R1-R10 需求体系与五节点系统架构
2. 理解 A/C/D/E/F 系列话题与服务接口定义、YAML 参数化配置与双模式机制
3. 掌握 KWS→ASR→LLM→TTS 语音链路、AprilTag 视觉检测与 PnP 位姿解算原理
4. 理解激光雷达安全联锁(扇区检测/释放力矩/解除恢复)与打断分层机制

### 1.2 能力目标
通过本课程的学习，学生能够：
1. 具备在 B2/C1 平台一键启动智慧工厂系统并完成全链路验证的能力
2. 能够独立完成语音交互、视觉装货、分拣、码垛、危险急停五大模块的集成测试
3. 能够通过 yaml 配置调优抓取点位、HSV/标签参数与安全阈值，解决实际偏差
4. 能够基于接口清单与源码定位问题，完成故障排查与系统停止清理

### 1.3 素养目标
通过本课程的学习，学生能够：
1. 养成"先预演仿真、后实机验证"的工程安全意识
2. 具备多模块(语音/视觉/机械臂/流水线/安全)协作的团队开发精神
3. 树立对实机安全联锁、力矩保护与资源约束的工程伦理意识

## 三、教学内容

### 第1章 项目需求与系统架构

#### 教学内容
- R1-R10 需求体系（装货/分拣/码垛 + 安全联锁 + 语音交互 + 打断复位）
- 五节点架构：N1语音/N2调度/N-vision/N-grasp/N-conveyor + N3安全
- 话题/服务通信拓扑与复用节点体系（car1_bringup/arm_controller/peripherals）
- N2 调度器任务状态机与 palletize 先送料后抓取编排、未就绪自动重试

#### 重点难点
- **重点**: 五节点职责划分；任务状态机；需求到架构的映射
- **难点**: 话题与服务混合通信拓扑；palletize 跨节点编排

#### 教学活动
- [x] 讲授：docs/01_需求总览.md 与 docs/02_架构设计.md
- [x] 动手实验：exp01 需求分析 + exp02 架构设计（源码阅读）

#### 对应知识点
1.1.1~1.3.3 需求体系/任务流程/安全联锁需求/五节点架构/通信拓扑/复用节点/任务状态机/palletize编排/自动重试

### 第3章 语音交互

#### 教学内容
- KWS 唤醒词配置与 ASR 热词（modified_beam_search）

#### 重点难点

- **难点**: 热词与意图提示词调优；打断机制与任务中止

### 第5章 分拣码垛与流水线

#### 教学内容
- 固定点位抓取（vision=false）与手动打点方法
- 流水线电机控制（复用底盘电机 M1）与光电传感器定点停
- 流水线状态机（idle/running/sensor_blocked/emergency）与急停复位
- palletize 先送料后抓取编排（docs/09、docs/10 测试用例）

#### 重点难点
- **重点**: 手动打点；run_until_sensor 定点停；palletize 编排
- **难点**: 光电防抖；急停复位状态机

#### 对应知识点
5.1.1~5.2.3 固定点位抓取/打点/动作原语/流水线/定点停/状态机

### 第6章 安全联锁与系统验证

#### 教学内容
- 激光雷达前方扇区检测（60°/20cm/0.5s）与危险判定
- 危险时释放 6 舵机力矩（/car1_base_driver/bus_servo/set_state）
- 危险解除恢复与回 work、打断分层（雷达>语音）
- 一键启动 7 开关模块化与全链路快速验证、停止清理

#### 重点难点
- **重点**: 扇区检测参数；力矩释放保护；全链路闭环验证
- **难点**: 打断分层优先级；N-grasp/conveyor 的 danger 响应

#### 教学活动
- [x] 演示：低内存雷达安全单测
- [x] 动手实验：exp08 具身智能工厂--危险急停集成测试 + exp09 全功能快速验证

#### 对应知识点
6.1.1~6.3.3 雷达安全/恢复机制/系统集成验证
