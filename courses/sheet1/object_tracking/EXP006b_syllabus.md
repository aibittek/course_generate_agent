## 一、课程目标

### 1.1 知识目标
通过本课程的学习，学生能够：
1. 掌握通用目标追踪综合项目 R1-R13 功能需求体系与七层模块架构（apps/common/tracking/tools/speech/llm/vision/config）
2. 理解 track_config.yaml 全键配置体系、config_schema 校验机制与 CLI 覆盖规则
3. 掌握 YOLOv8 检测（RKNN NPU）+ DeepTrack 多目标追踪（卡尔曼预测 + IoU/外观级联关联 + ReID 外观重识别）的视觉流水线
4. 理解 LLM FunctionCall 工具调用（track_ids/clear_track）与独立线程 CommandWorker 不卡帧机制
5. 掌握 VLM 视觉选目标（网格构图→绝对 track id）与门控路由 fail-closed 铁律
6. 理解 XFM 六麦唤醒→KWS→流式 ASR→流式 TTS 播报的完整语音链路与事件日志故障降级体系

### 1.2 能力目标
通过本课程的学习，学生能够：
1. 具备在 B2/C1 平台上独立部署并运行通用目标追踪系统全链路的能力
2. 能够独立完成多目标追踪底座、LLM 指令门控、VLM 选车、语音交互、事件日志五大模块的集成测试与故障排查
3. 能够通过 track_config.yaml 配置调优检测阈值、追踪参数与门控词表，解决场景偏差
4. 能够基于源码定位问题，完成命令行工具（--text/--video/--camera/--mjpeg）调试与全链路验证

### 1.3 素养目标
通过本课程的学习，学生能够：
1. 养成"先文本离线验证、后实时部署"的嵌入式 AI 工程安全意识
2. 具备视觉+大模型+语音+门控多模块协作的系统集成开发精神
3. 树立对 fail-closed（不确定不动作）、边缘资源约束与隐私安全的工程伦理意识

### 第3章 多目标追踪底座

#### 教学内容
- DeepSORT 结构：卡尔曼预测+IoU/外观级联关联+确认框
- 卡尔曼常速模型（8维均值+4维协方差）按框高缩放噪声，CHI2INV95 门控
- min_box_w/h=32 小框剔除 + max_stale=15 超龄剔除
- deepsort.rknn 外观特征（64x128 ImageNet 归一化）与 ReIDPool 多线程异步池
- min_confidence=0.3 与 class_filter=[car] 实机 tuning 保障 ID 稳定
- COCO 80 类通用目标与 track_demo ID 底座验证

#### 重点难点
- **重点**: 卡尔曼预测+级联关联；ReID 外观消除单帧漏检换 ID
- **难点**: min_box/max_stale 过滤与 ID 稳定性调参；ReID 降级纯 IoU

#### 教学活动
- [x] 讲授：docs/08_视觉测试用例.md 与 docs/02_架构设计.md 追踪引擎

### 第4章 LLM指令与门控

#### 教学内容
- LLM Function Call 工具调用：(track_ids/clear_track) 独立线程不卡
- 原生 rkllm 原生 FunctionCall 与结构化 JSON dispatch 双路径
- rules 兜底 parse_instruction 正则提取指令（id/颜色/清除）
- _native_gate 门控路由顺序：清除短路/非指令回落对话/无 id 描述走 VLM
- clear_words 强制 clear_track 与 ID 数值不对齐「未找到」
- VLM 网格构图选择目标 + fail-closed 铁律

#### 重点难点
- **重点**: LLM Function Call 与 CommandWorker 异步消费；门控路由顺序
- **难点**: fail-closed 语义（绝不锁错目标）；VLM 网格编号→绝对 id 映射

### 第6章 事件日志与故障降级

#### 教学内容
- events.jsonl 追加记录（lost/unlock_all/command/camera_stall/pause_timeout）事后追责
- fail-closed 降级原则：任何「不确定锁谁」分支不产副作用
- 故障注入：断网 ReID / 相机断流 / aplay 被杀 / 无 VLM，降级不崩线程
- 三模式入口（--video/--image/--camera）与文本→语音→摄像头三级验证
- MJPEG :8088/track.mjpg 实时预览与全链路故障排查

#### 重点难点
- **重点**: 事件日志记录与事后追责；fail-closed 降级一致性
- **难点**: 故障注入测试设计；三模式全链路闭环验证与残留进程清理
