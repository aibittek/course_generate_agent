## 一、课程目标

### 1.1 知识目标
通过本课程的学习，学生能够：
1. 理解 SLAM 的基本原理（同时定位与地图构建、"鸡生蛋蛋生鸡"）与占据栅格地图的表示方法
2. 掌握 URDF/Xacro 机器人建模与 RViz 可视化的基本方法
3. 掌握 slam_toolbox 二维激光建图的配置、操控、保存与质量评估
4. 掌握 Nav2 自主导航的架构（全局规划/局部规划/行为树）与基本使用
5. 理解 AMCL 粒子滤波定位原理与参数配置
6. 理解 DWA/DWB/TEB 局部规划与动态避障原理
7. 了解 RTAB-Map 三维视觉 SLAM 与三维导航的概念与流程

### 1.2 能力目标
通过本课程的学习，学生能够：
1. 独立完成"遥控建图 → 保存地图 → 加载导航 → 下达目标 → 避障到达"完整闭环
2. 能够读懂并修改 slam.yaml / nav2_params.yaml 关键参数，解决常见故障（地图重影、定位丢失、无法避障等）
3. 能够使用 RViz / ros2 命令行（topic/action/param）完成定位与导航的调试验证
4. 能够评估建图与导航质量（墙厚、尺寸误差、到达率、避障成功率）

### 1.3 素养目标
通过本课程的学习，学生能够：
1. 养成"先低速试跑、后全速运行"的工程安全意识
2. 具备"参数调整 → 现象观察 → 定位原因"的工程调试思维
3. 树立对实机电机、雷达等硬件的爱护与规范操作意识

## 三、教学内容

### 第1章 建图原理与URDF建模

#### 教学内容
- SLAM 概念与建图三要素（感知 → 定位 → 构图）
- 占据栅格地图（OccupancyGrid）表示
- URDF 结构（link/joint）与 Xacro 宏
- car1.urdf 三大部分解析（主体/机械臂/爪子）
- display.launch.py 三件套可视化

#### 重点难点
- **重点**: SLAM 直觉理解；URDF 的 link/joint 概念
- **难点**: 无（纯入门）

#### 教学活动
- [x] 讲授：白话讲解"蒙眼逛新家"类比 + URDF 语法
- [x] 动手实验：exp01 URDF 模型加载与 RViz 观察

#### 对应知识点
1.1.1~1.5.2 建图原理/URDF/建图环境/判断标准

---

### 第2章 基于SLAM_Toolbox的二维激光建图

#### 教学内容
- slam_toolbox 框架（前端 Scan Match / 后端 Ceres / 回环检测）
- 关键参数（resolution/关键帧阈值/loop_closing）
- slam.launch.py 分层启动 + slam_teleop 键盘遥控
- 地图保存（pgm/yaml）与质量验收（墙厚/尺寸/直角/闭环）

#### 重点难点
- **重点**: 建图全流程；回环检测的作用
- **难点**: 参数对地图质量的影响（阈值大小、分辨率）

#### 教学活动
- [x] 演示：完整建图一次 → 保存 → 评估
- [x] 动手实验：exp02 遥控建图 + 参数对比

#### 对应知识点
2.1.1~2.5.1 框架/参数/启动操控/保存/评估

---

### 第3章 基于Nav2的机器人自主导航

#### 教学内容
- Nav2 五大服务器与 Lifecycle 管理
- 全局路径规划（ThetaStarPlanner）与全局代价地图
- 局部路径规划（DWB FollowPath）与局部代价地图
- 行为树（bt_navigator）与两个导航器
- navigation.launch.py 一键启动与目标下发

#### 重点难点
- **重点**: Nav2 架构；导航闭环（地图→定位→规划→执行）
- **难点**: 行为树流程理解；代价地图分层

#### 教学活动
- [x] 演示：加载地图 → 下发目标 → 机器人自主到达
- [x] 动手实验：exp03 自主导航全流程

#### 对应知识点
3.1.1~3.5.3 架构/全局/局部/行为树/启动与目标

---

### 第4章 基于AMCL的自适应蒙特卡罗定位

#### 教学内容
- 定位问题（里程计漂移）与雷达比对定位
- 粒子滤波三步骤（预测/更新/重采样）与自适应粒子数
- AMCL 参数配置（粒子数/运动噪声/likelihood_field/初始位姿）
- 定位验证（粒子收敛观察）与 kidnapped robot 恢复

#### 重点难点
- **重点**: 粒子滤波直觉理解；初始位姿设置
- **难点**: 参数与收敛速度/精度的权衡

#### 教学活动
- [x] 演示：粒子收敛过程 + 搬走机器人重定位
- [x] 动手实验：exp04 定位调试与参数对比

#### 对应知识点
4.1.1~4.4.2 定位问题/粒子滤波/参数/验证
