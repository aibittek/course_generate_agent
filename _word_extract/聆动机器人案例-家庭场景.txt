聆动机器人案例-家庭场景
1 场景介绍
在实验开始之前，需要保证环境的安全，机械臂抓取范围内不能站人，避免误伤。桌面可适当做保护，避免机械臂砸伤桌子。
家庭场景以收纳为主，在单机械臂场景中，一般有以抓-拿-放的准则设计实验场景，拓展到双臂中，可以双臂配合，例如左手打开容器盖子，右手放入物品，左手再放回容器盖子。场景默认布局如下：
操作流程为，左手打开不锈钢盒子的盖子，右手拿起桌面的芒果，放入罐子中，左手关闭盖子。
布置好场景，可以对场景数据做简单测量，避免实验场景被破坏而难以复现，例如测量桌面到机械臂的距离，这个距离尽可能保持一致，否则会出现复现效果较差的情况。桌面物品摆放的大致方位，也可进行测量，这部分可以不需要太准确，采集数量足够大时，场景发生小范围变动也可以复现。

2 数据采集
2.1 设备开机

[表格]
   | 
按下操作端侧面总电源和从动臂电源，如果设备未正常开机，可以打开操作端侧面的门，按下主机上的开机按钮。开机后从动臂机械夹爪会张开再收起，如果没动则可能是机械臂启动失败。
进入登陆界面后，输入密码（密码为1），进入Ubuntu桌面，点击谷歌浏览器，输入localhost:8699/#/robotManage进入具身智能机器人平台，或者点击书签，点击绿色的一键 启动按钮。
等待进度条读条，读条结束后，启动后设备进入“遥操作状态”。
此时同时操作左右手的夹爪，可以进行遥操作，操作主臂带动从臂运动。在正式开始数据采集之前，可以通过遥操作，熟悉要进行的实验流程。
2.2 新建任务
点击“具身智能机器人平台”中的任务管理按钮，右上角选择新建任务
填写任务名，任务描述，采集数量可以写一些，不必全部采集完。
任务创建之后点击保存按钮。
2.3 遥操作采集
任务创建完成之后开始任务，先点击1开始，然后点击2预览，进入以下界面
布置好场景后，点击开始数据采集，随后机械臂会进入采集状态，控制端和机械臂端都会进入固定动作，在三秒内要握持住操作端，随后页面出现三个摄像头的画面。
按照前面预演的流程，完成操作，左手打开不锈钢盒子的盖子，右手拿起芒果并放入，右手放回盖子。完成之后点击“停止当前组数据采集”，一组数据采集完成。
依次循环，根据采集任务的复杂程度采集合适数量的数据。
2.4 错误任务标记
如果采集过程中出现失误，可以点击本次采集失败按钮，这组数据不计入训练（如果使用云平台或者自己转换数据二次开发，可以手动记录编号）。
记录后，本机训练将不会计入，采集失败的数据尽量排除，否则可能导致训练效果不佳。
3 数据转换
首先找到本地数据，在/home/lindenbot/save_data路径下，数字最大的那个就是最新建的数据，使用课程文件中convert_lerobot_v3_fixed_simple.py脚本进行数据转换，分为几个情况的使用。注意 文件中的编号一般不是从0开始，例如文件夹中的数据是180到280，则180对应的是该任务中采集的第一个数据，280是最后一个数据，编号按照这个顺序对应，因此前面记录的错误数据，也要加上179，例如第50组数据采集错误，则对应了文件夹中的229号数据。
场景 1：转换指定范围（最常用）

[表格]
  Bashpython convert_lerobot_v3_fixed_simple.py \    --input /home/lindenbot/save_data/11 \    --output /home/lindenbot/converted_data \    --start 180 \    --end 209

[表格]
  如果没有出现采集错误，或者直接取一段完成的数据，可以直接用这个编号来指定范围，转换对应的数据
场景 2：跳过采集失败的 episode

[表格]
  Bashpython convert_lerobot_v3_fixed_simple.py \    --input /home/lindenbot/save_data/11 \    --output /home/lindenbot/converted_data \    --start 180 \    --end 209 \    --skip 163,172,202

[表格]
  这个命令用于选取一段连续数据，但是其中存在部分采集失败的情况，将采集失败的编号放入skip中
场景 3：自定义任务名称

[表格]
  Bashpython convert_lerobot_v3_fixed_simple.py \    --input /home/lindenbot/save_data/11 \    --output /home/lindenbot/converted_data \    --start 200 \    --end 250 \    --task "place fruits in the box"

[表格]
  任务名称会写入 meta/tasks.parquet 和每个 episode 的元数据中。用于前面数据采集是任务详情写错的情况

3 数据训练
3.1 本地训练
*本地环境安装参考手册《03-聆动机器人数据训练》
本地数据转换完成之后，将课程包中的lerobot-0.4.1代码放到路径/home/lindenbot下，按照《03-聆动机器人数据训练》完成环境安装，然后开始训练。

[表格]
  Plain Textcd /home/lindenbot/lerobot-0.4.1lerobot-train \  --policy.type=act \  --dataset.repo_id=lindenbot/put_fruit_in_box\  --dataset.root=/home/lindenbot/converted_data\  --output_dir==/home/lindenbot/lerobot-0.4.1/outputs/put_fruit_in_box\  --job_name="place fruits in the box"\  --batch_size=12 \  --steps=50000 \  --save_freq=4000 \  --log_freq=100 \  --num_workers=8 \  --wandb.enable=false \  --policy.push_to_hub=false \  --policy.use_amp=true
名词解释：
policy.type 训练模型类型
dataset.root   输入路径，将数据传输解压到当前路径
output_dir 输出路径，训练完数据放在这里
steps 训练步数
job_name  任务名称，建议用英文简易描述任务内容
save_freq   每多少训练步数保存一次（保存的节点已经可以使用）
log_freq  日志打印频率
完成训练的数据在路径/home/lindenbot/lerobot-0.4.1/outputs/put_fruit_in_box下，后续推理需要用到这个路径

5 复现效果评估
将环境恢复至采集阶段，按照上述步骤进行推理，一般环境变化不大，机械臂可自行完成前面的任务。
如果出现机械臂不能完成任务，首先检查桌面环境参数与预设是否一致，其次检查采集和训练次数是否足够，对于任务中相对简单的任务 一般建议采集数据在200次左右，训练步数在500000步以上。
机械臂能自主将芒果放入不锈钢盒子中则任务完成。
