1.6 安装常见问题排查
1.6.1 问题 1：torch.cuda.is_available() 返回 False

[表格]
  可能原因：  - CUDA 驱动版本与 PyTorch 不匹配  - 安装的 PyTorch 是 CPU 版本解决方案：  1. 确认驱动版本：nvidia-smi  2. 确认 PyTorch CUDA 版本匹配：     python -c "import torch; print(torch.version.cuda)"  3. 如果不匹配，卸载重装对应版本的 PyTorch：     pip uninstall torch torchvision torchaudio     pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
1.6.2 问题 2：ModuleNotFoundError: No module named 'evdev'

[表格]
  原因：在 WSL 环境中缺少 evdev 库WSL 解决方案：  在 Windows 主机上安装 usbipd，然后连接 USB 设备  或者跳过 evdev 相关功能纯 Ubuntu 解决方案（无需处理，evdev 已内置在 Linux 内核中）
1.6.3 问题 3：ImportError: libGL.so.1: cannot open shared object file

[表格]
  原因：缺少 OpenCV 的系统依赖解决方案：  sudo apt install libgl1-mesa-glx  # 或者在 conda 环境中：  pip install opencv-python-headless  # 无头版，不依赖 libGL
1.6.4 问题 4：pip install -e . 超慢或卡住

[表格]
  Plain Text原因：下载 PyTorch 或其它大包解决方案：  1. 先手动安装 PyTorch（按 3.2 节）  2. 设置 pip 国内镜像源（按 1.4 节）  3. 单独安装大包后再运行 pip install -e .

2.2 训练环境搭建
训练平台选择，此处以算力自由平台为例，打开网站https://www.gpufree.cn/home。
点击控制台，再点击租用实例

进入后点击终端可以进入设备
打开终端后执行一下命令，安装训练环境

[表格]
  cd /data/lerobot/pip install -e .
2.2 本地数据转换

[表格]
  python convert_lerobot_v3_fixed.py \    --input /你的/原始数据路径 \    --output /你的/输出路径 \    --start 1 --end 50 \    --task "你的任务描述"
运行脚本进行数据转换（详细流程查看”聆动机器人数据转换“）

[表格]
  zip -r data.zip  data
转换后将数据打包
2.3在线训练
 将转换的数据打包后上传至/root/gpufree-data路径下，解压，点击下图中按钮进行上传；
进入训练路径，执行训练命令

[表格]
  cd /data/lerobot/lerobot-train \  --policy.type=act \  --dataset.repo_id=$task_name$\  --dataset.root=/root/gpufree-data/data/$input_data$\  --output_dir=/root/gpufree-data/outputs/$output_data$\  --job_name=$job_name$\  --batch_size=12 \  --steps=50000 \  --save_freq=4000 \  --log_freq=100 \  --num_workers=8 \  --wandb.enable=false \  --policy.push_to_hub=false \  --policy.use_amp=true
名词解释：
policy.type 训练模型类型
dataset.root   输入路径，将数据传输解压到当前路径
output_dir 输出路径，训练完数据放在这里
steps 训练步数
job_name  任务名称，建议用英文简易描述任务内容
save_freq   每多少训练步数保存一次（保存的节点已经可以使用）
log_freq  日志打印频率
2.4 问题解决
显存不足，报错信息通常为：torch.OutOfMemoryError: CUDA out of memory.
     解决办法：降低训练参数中的batch_size
