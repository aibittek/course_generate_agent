1.2 类和方法逐层分析
1.2.1 init() — 初始化（L32-L63）

[表格]
  pythonclass LeRobotV3Converter:    def __init__(self, input_dir, output_dir, episode_ids=None, fps=30, skip_episodes=None, task_name=None):
存储的核心配置：
input_dir / output_dir：输入输出目录（自动转 Path 对象）
fps = 30：视频帧率
chunks_size = 1000：每个 chunk 目录最多容纳的文件数（LeRobot v3.0 的分片约定）
episode_ids：指定要转换的 episode ID 列表（如 [180, 181, ..., 209]）
skip_episodes：要跳过的 episode ID 列表（处理采集失败的 episode）
joint_names：16 个关节的名称（左臂 8 + 右臂 8）
camera_mapping：摄像头映射 cam_head→side、cam_left→left、cam_right→right
task_name：VLA 任务描述文本
1.2.2 get_episode_dirs() — 获取 Episode 目录（L65-L93）
两种模式：

[表格]
  模式 A：指定 episode_ids（通过 --start/--end）  └─ 遍历 [start..end]，检查每个 ID 是否存在目录、是否在 skip 列表模式 B：自动扫描（不传 episode_ids）  └─ 遍历 input_dir 下所有纯数字目录名，排序后过滤 skip 列表
返回 list[Path]，每个元素是一个 episode 目录的绝对路径。

[表格]
  <输入目录>/├── 180/                       ← 数字命名的 episode 文件夹│   ├── robot_data.csv         ← 30fps 的机器人关节数据│   ├── cam_head/│   │   └── cam_head.mp4       ← 头部摄像头视频│   ├── cam_left/│   │   └── cam_left.mp4       ← 左侧摄像头视频│   └── cam_right/│       └── cam_right.mp4      ← 右侧摄像头视频├── 181/                       ← 下一个 episode│   ├── robot_data.csv│   ├── cam_head/│   │   └── cam_head.mp4│   ├── cam_left/│   │   └── cam_left.mp4│   └── cam_right/│       └── cam_right.mp4├── 182/└── ...

  视频合并失败: [concat @ ...] Stream packet data not seen, referred to as non-keyframe                                                      ↓原因：使用 -c copy 时，FFmpeg 要求所有输入视频的编码参数完全一致      （编码器、分辨率、帧率、像素格式、GOP 结构等）解决方案：  1. 先检查各episode视频编码是否一致：     ffprobe -v quiet -print_format json -show_streams episode_180/cam_head/cam_head.mp4     ffprobe -v quiet -print_format json -show_streams episode_181/cam_head/cam_head.mp4     # 对比 codec_name, width, height, pix_fmt, r_frame_rate 等字段  2. 如果不一致，改用 fixed.py（会重编码）：     python convert_lerobot_v3_fixed.py --input ... --output ...  3. 或用 fixed_simple.py 但先统一编码：     手动用 ffmpeg 将所有视频转为统一规格再运行
