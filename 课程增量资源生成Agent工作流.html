具身智能课程资源生成框架 · workflow v3.0 (simplified)

源码驱动 · 双 Agent 流程 · PreToolUse hooks 强制约束 · 支持单实验/批量生成

简化双 Agent 流程

  • • Step1: SourceCodeAnalysisAgent 分析源码
  • • 输出: code-analysis-report.md + analysis-status.yaml
  • • Step2: LabGuideExperimentAgent 生成实验内容
  • • 输出: 单实验指导书段落（9 个必需部分）
  • • 支持单实验/批量生成两种模式

PreToolUse Hooks 强制约束

  • • enforce-source-hook.ps1 拦截 Task 工具
  • • enforce-source-on-edit.ps1 拦截 Edit/Write/MultiEdit
  • • 校验: analysis-status == completed
  • • 未完成源码分析 → exit 2 (BLOCK)
  • • 防止绕过约束直接修改实验内容

源码驱动的内容生成

  • • 源码分析提取框架/原理/易错点
  • • 实验步骤引用源码位置（文件名+行号）
  • • 原理讲解≥80字 · 公式推导 · 算法说明
  • • 知识点对齐 · 学习路径规划
  • • 移除复杂 6 步流程，专注源码→实验映射
