# 具身智能实验平台 硬件规格

> **产品1**: 具身智能实验箱B2，型号XFLZ_EAI_B2_PRO
> **产品2**: 具身智能机器人小车C1，型号XFLZ_EAI_CAR1
> **品牌**: 科大讯飞
> **定位**: 具身智能核心实验平台

---

## 一、产品定位

### 1.1 具身智能实验箱B2（XFLZ_EAI_B2_PRO）
- **定位**: 具身智能核心教学实验平台
- **应用**: 计算机视觉、语音处理、机械臂控制、大模型交互、智能家居、智慧康养
- **集成核心**: 计算机视觉系统、六麦克风阵列、6DOF机械臂、深度相机、激光雷达、IMU
- **集成扩展**: 指纹、温湿度、光电、气敏、RFID、MAX30102心率传感器、继电器
- **人机交互**: 19寸显示屏、触控键盘、内置扬声器

### 1.2 具身智能机器人小车C1（XFLZ_EAI_CAR1）
- **定位**: 移动机器人实验平台
- **竞赛**: 支持全国大学生智能汽车大赛、金砖国家职业技能大赛
- **集成**: 计算机视觉系统、语音处理系统、机械手臂、深度相机、激光雷达、里程计

# ✅ 推荐：轻量化模型（适合6TOPS算力）

## 十、平台对比

| 对比项 | 具身智能实验箱B2 | 具身智能机器人小车C1 |
|--------|-----------------|-------------------|
| **型号** | XFLZ_EAI_B2_PRO | XFLZ_EAI_CAR1 |
| **定位** | 桌面实验平台 | 移动机器人平台 |
| **机械臂** | ✅ 6DOF | ✅ 6DOF |
| **移动能力** | ❌ | ✅ 麦克纳姆轮全向移动 |
| **激光雷达** | ✅ 360°激光雷达 | ✅ 360°激光雷达 |
| **深度相机** | ✅ 结构光深度相机 | ✅ 结构光深度相机 |
| **IMU** | ✅ BMI088 | ✅ BMI088 |
| **适用课程** | 视觉、语音、机械臂、ROS仿真、传感器 | ROS实机、SLAM、导航、综合应用 |
| **竞赛支持** | - | 智能汽车大赛、金砖大赛 |

**选择建议**：
- **计算机视觉、语音、大模型课程**：B2或C1均可
- **机器人ROS2应用与开发**：B2（仿真为主，可选C1实机）
- **SLAM定位导航**：C1（必须，需要移动底盘）
- **移动机器人、竞赛**：C1（具备移动底盘）
- **综合实训**：B2（桌面场景） + C1（移动场景）组合
