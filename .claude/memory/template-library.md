## 四、练测题模板

```markdown
# {课程名称} 练测题库

> 总题目数: {数量}
> 预计考试时长: {时长}

---

## 第一章 练习题

### 一、单项选择题（每题2分）

**1. [知识点1.1.1]** {题目}
A. {选项A}
B. {选项B}
C. {选项C}
D. {选项D}

**答案**: {A}
**解析**: {简要解析}

### 二、多项选择题（每题4分）

**1. [知识点1.1.2]** {题目}
A. {选项A}
B. {选项B}
C. {选项C}
D. {选项D}

**答案**: {AB}
**解析**: {简要解析}

### 三、简答题（每题10分）

**1. [知识点1.2.1]** {问题}

**参考答案**:
1. {要点1}
2. {要点2}
3. {要点3}

### 四、编程题（每题20分）

**1. [知识点2.3.1]** {编程要求}

````python
# 参考代码框架
def solve():
    pass
````

**评分标准**:
| 等级 | 分数 | 标准 |
|-----|------|------|
| 优秀 | 18-20 | 代码正确完整 |
| 良好 | 14-17 | 代码正确 |
```
