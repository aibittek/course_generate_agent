# 内容准确性规则

本文档定义确保课程内容准确性的检查规则，是最高优先级的质量要求。

---

## 一、知识正确性

### 1.1 技术术语
| 检查项 | 要求 |
|-------|------|
| 使用标准术语 | 必须使用业界公认术语 |
| 首次出现标注 | 提供英文或解释 |
| 全文一致 | 同一术语不混用 |

### 1.2 示例规范
```markdown
正确: ROS2是机器人操作系统2代
正确: Robot Operating System 2 (ROS2)

错误: 那个ROS系统（应明确版本）
```

---

## 二、代码正确性

### 2.1 语法检查
| 语言 | 检查项 |
|------|-------|
| Python | 无SyntaxError |
| C++ | 无编译错误 |
| Bash | 无命令错误 |
| YAML | 格式正确 |

### 2.2 示例
```python
# ✅ 正确
def hello():
    print("Hello")

# ❌ 错误
def hello()
    print("Hello")
```

---

## 三、公式与算法

### 3.1 公式正确性
- 数学公式推导正确
- 物理公式符合定律
- 算法描述准确

### 3.2 示例
```markdown
正确: 运动学方程: θ = arctan2(y, x)

错误: θ = sin(y/x) （应使用atan2）
```

---

## 四、禁止内容

### ❌ 严格禁止
1. **过时术语**
   - ROS1特有的概念（ROS2场景下）
   - 已废弃的API

2. **未验证信息**
   - 未经确认的技术细节
   - 夸大功能描述

3. **矛盾描述**
   - 与培养方案矛盾
   - 章节间逻辑矛盾

4. **错误代码**
   - 语法错误
   - 逻辑错误
   - 安全隐患

### 4.1 示例
```markdown
❌ 错误: ROS2使用rospy.Subscriber订阅话题
❌ 错误: 机械臂精度可达0.001mm（夸大）

✅ 正确: 使用rclpy.node.Node创建节点
✅ 正确: 机械臂重复精度±0.02mm
```

---

## 五、行业对齐检查

### 5.1 产业需求对齐
| 检查项 | 标准 |
|-------|------|
| 技能对应 | 与岗位技能要求匹配 |
| 工具对应 | 与产业常用工具一致 |
| 术语对应 | 与行业标准一致 |

### 5.2 设备能力对齐
| 检查项 | 标准 |
|-------|------|
| 功能匹配 | 描述与设备能力一致 |
| 参数合理 | 在设备参数范围内 |
| 版本正确 | 标注软件版本 |

---

## 六、审核流程

### 6.1 自检清单
生成完成后，Agent必须检查：
- [ ] 技术术语是否标准
- [ ] 代码是否有语法错误
- [ ] 公式推导是否正确
- [ ] 是否有过时内容
- [ ] 是否与培养方案矛盾

### 6.2 问题标记
发现问题使用以下标记：
```markdown
[⚠️ 待核实] - 需要人工确认的内容
[❌ 错误] - 已确认的错误
```
