# 输出格式规范

本文档定义课程资源文档的Markdown格式标准。

---

## 一、标题层级

### 1.1 标准层级
| 层级 | 语法 | 用途 | 数量限制 |
|------|------|------|---------|
| 一级 | `# 标题` | 文档主标题 | 每文档1个 |
| 二级 | `## 标题` | 大章节 | 根据内容 |
| 三级 | `### 标题` | 小节 | 根据内容 |
| 四级 | `#### 标题` | 子节 | 最多2层 |

### 1.2 示例
```markdown
# 课程名称 知识图谱

## 第1章 感知技术基础

### 1.1 视觉感知

#### 1.1.1 图像基础
内容...
```

## 二、表格格式

### 2.1 标准表格
```markdown
| 列1 | 列2 | 列3 |
|------|------|------|
| 内容 | 内容 | 内容 |
| 内容 | 内容 | 内容 |
```

### 2.2 表头样式
```markdown
| 列1 | 列2 | 列3 |
|:----|:---:|---:|
| 左对齐 | 居中 | 右对齐 |
```

### 2.3 表格前后
- 表格前空一行
- 表格后空一行

---

## 三、列表格式

### 3.1 无序列表
```markdown
- 第一项
- 第二项
  - 嵌套项（缩进2空格）
  - 嵌套项
- 第三项
```

### 3.2 有序列表
```markdown
1. 第一步
2. 第二步
3. 第三步
```

### 3.3 任务列表
```markdown
- [ ] 未完成任务
- [x] 已完成任务
```

### 3.4 嵌套限制
- 最多嵌套3层
- 使用2空格缩进

### 4.1 必须指定语言
````markdown
```python
````

```markdown
使用 `print()` 函数

```

### 4.3 代码块前后
- 代码块前空一行
- 代码块后空一行

## 五、强调格式

| 语法 | 效果 | 用途 |
|------|------|------|
| `**粗体**` | **粗体** | 重点强调 |
| `*斜体*` | *斜体* | 术语引用 |
| `***粗斜***` | ***粗斜*** | 特别强调 |
| `` `代码` `` | `代码` | 代码、命令 |

## 八、Emoji使用

### 8.1 允许的Emoji
| Emoji | 含义 | 使用场景 |
|-------|------|---------|
| ✅ | 完成/正确 | 状态标记 |
| ❌ | 错误/禁止 | 状态标记 |
| ⚠️ | 警告/注意 | 提醒事项 |
| 🔴 | 严重/紧急 | 问题级别 |
| 🟡 | 一般/中等 | 问题级别 |
| 🟢 | 正常/轻微 | 问题级别 |
| ⭐ | 优秀/推荐 | 评级标记 |
| ⏳ | 等待/待处理 | 状态标记 |
| 🔄 | 进行中 | 状态标记 |

### 8.2 禁止的Emoji
- ❌ 表情符号（😊😂等）
- ❌ 旗帜符号
- ❌ 复杂图形

## 十、禁止规则

### ❌ 禁止的行为
1. 手绘表格边框
2. 连续超过2行空行
3. 使用非标准Markdown语法
4. 嵌套超过3层的列表
5. 标题跳级（如#后直接###）
6. 代码块不指定语言
