# 版本管理规范

本文档定义课程资源的版本号规则和变更记录格式。

---

## 一、版本号规则

### 1.1 版本格式
```
v{主版本}.{次版本}
```

### 1.2 版本定义
| 级别 | 触发条件 | 示例 |
|------|---------|------|
| 主版本 | 重大结构调整、新增章节、删除内容 | v1.0, v2.0 |
| 次版本 | 内容更新、错误修正、补充完善 | v0.1, v0.2 |

### 1.3 版本演进
```
v0.1 → v0.2 → v0.3 → ... → v1.0
                         ↑
                    重大更新
```

---

## 二、版本号判断标准

### 2.1 主版本更新条件
满足任一条件时升级主版本：
- 新增章节（≥1章）
- 删除章节或内容
- 结构调整（章节重组）
- 教学目标重大变更
- 考核方式重大变更

### 2.2 次版本更新条件
满足任一条件时升级次版本：
- 补充知识点
- 修正错误
- 完善实验步骤
- 补充思考题
- 优化表述
- 格式调整

## 三、文档头部版本信息

### 3.1 必需版本信息
```markdown
---
title: {课程名称} 知识图谱
version: v0.1
last_updated: 2026-06-11
updated_by: Agent
---
```

### 3.2 格式示例
```markdown
---
title: 机器人ROS2应用与开发 知识图谱
version: v0.1
last_updated: 2026-06-11
updated_by: Agent
---

# 机器人ROS2应用与开发 知识图谱

> 版本: v0.1
> 更新日期: 2026-06-11
```

## 五、文件命名版本

### 5.1 当前版本文件
```
{课程标识}_{文档类型}.md
```

### 5.2 历史版本文件
```
{课程标识}_{文档类型}_v{版本号}.md
```

### 5.3 示例
```
cv_practice_knowledge_graph.md          # 当前版本
cv_practice_knowledge_graph_v0.1.md     # 历史版本
cv_practice_knowledge_graph_v0.2.md     # 历史版本
```

## 六、版本发布流程

### 6.1 草稿版本（v0.x）
1. Agent生成 → v0.1
2. 如需修改 → v0.2, v0.3...
3. 累积修改直到稳定

### 6.2 正式版本（v1.x）
1. 人工审核通过
2. 升级到v1.0
3. 进入正式发布

### 6.3 更新版本（v1.x → v2.x）
1. 发现重大问题或需求变更
2. 修改后发布v1.1, v1.2...
3. 重大结构调整 → v2.0

## 七、版本控制命令

### 7.1 备份命令
```bash
# 备份当前版本
cp cv_practice_knowledge_graph.md cv_practice_knowledge_graph_v0.1.md
```

### 7.2 归档命令
```bash
# 归档旧版本
mkdir -p archive
mv cv_practice_knowledge_graph_v0.1.md archive/
```
