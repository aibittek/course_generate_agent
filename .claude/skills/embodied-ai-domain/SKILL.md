## 二、关键技术术语

### 2.1 ROS2核心概念
| 术语 | 全称 | 说明 |
|-----|-----|------|
| ROS2 | Robot Operating System 2 | 机器人操作系统2代 |
| Node | - | ROS中的独立执行单元 |
| Topic | - | 发布-订阅通信模式 |
| Service | - | 请求-响应通信模式 |
| Action | - | 长期任务通信模式 |
| Lifecycle | - | 节点生命周期管理 |
| DDS | Data Distribution Service | 数据分发服务 |
| Colcon | - | ROS2构建工具 |

### 2.2 SLAM相关术语
| 术语 | 全称 | 说明 |
|-----|-----|------|
| SLAM | Simultaneous Localization and Mapping | 即时定位与地图构建 |
| URDF | Unified Robot Description Format | 统一机器人描述格式 |
| Map | - | 环境地图表示 |
| Localization | - | 定位 |
| Path Planning | - | 路径规划 |
| Cartographer | - | Google开源SLAM系统 |
| GMapping | - | 基于粒子滤波的SLAM |

### 2.3 运动控制术语
| 术语 | 全称 | 说明 |
|-----|-----|------|
| MoveIt2 | - | 机械臂运动规划框架 |
| IK/FK | Inverse/Forward Kinematics | 逆/正运动学 |
| OMPL | Open Motion Planning Library | 开源运动规划库 |
| Trajectory | - | 轨迹 |
| Collision Detection | - | 碰撞检测 |
| SRDF | Semantic Robot Description Format | 语义机器人描述格式 |

### 2.4 大模型术语
| 术语 | 全称 | 说明 |
|-----|-----|------|
| VLM | Vision-Language Model | 视觉语言模型 |
| VLA | Vision-Language-Action | 视觉-语言-动作模型 |
| LLM | Large Language Model | 大语言模型 |
| Prompt | - | 提示词 |
| RAG | Retrieval-Augmented Generation | 检索增强生成 |
| Agent | - | 智能体 |
