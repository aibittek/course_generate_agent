# 课程开发工时测算技能

根据课程总课时和实验案例数量，自动计算纯人工独立开发与 AI Agent 人机协同两套工时方案，输出标准人月和效率对比报告。

---

## 一、固定业务常量

| 常量名 | 值 | 说明 |
|--------|-----|------|
| monthly_work_days | 20.75 | 月度标准有效工作日（天/月） |
| kp_per_hour | 3 | 每课时对应知识点数量 |
| question_per_kp | 3 | 单个知识点配套习题数量 |
| manual_question_output_per_day | 30 题/天 | 纯人工每日出题量 |
| ai_review_question_per_day | 100 题/天 | AI 生成后人工审核每日题量 |

---

## 二、固定工时基准配置

### 2.1 纯人工单人串行工时标准

| 产出模块 | 单套/单件工时 |
|---------|-------------|
| 全套课程大纲 | 2.5 天 |
| 单个案例完整代码开发 | 3.0 天 |
| 单份实验指导书撰写 | 1.5 天 |
| 全量知识点图谱梳理制作 | 5.0 天 |

### 2.2 AI Agent 人机协同工时标准

> AI 生成初稿，人工校验，配图、调试、修正。

| 产出模块 | 单套/单件工时 |
|---------|-------------|
| 全套课程大纲 | 0.5 天 |
| 单个案例代码（AI 初稿 + 人工调试适配） | 1.0 天 |
| 单份实验指导书（AI 初稿 + 配图/原理扩充） | 1.0 天 |
| 全量知识点图谱整理优化 | 0.5 天 |

---

## 三、自动推导变量计算逻辑

```
kp_total        = total_class_hour × kp_per_hour
question_total  = kp_total × question_per_kp
```

---

## 四、工时核算公式

### 4.1 纯人工总工作日

| 产出模块 | 公式 |
|---------|------|
| 课程大纲编制 | man_outline = 2.5 |
| 全部案例代码开发 | man_code = case_count × 3.0 |
| 全部实验指导书撰写 | man_doc = case_count × 1.5 |
| 全量知识点知识图谱 | man_graph = 5.0 |
| 题库出题（含审核） | man_question = question_total ÷ manual_question_output_per_day |

```
total_day_man   = man_outline + man_code + man_doc + man_graph + man_question
man_month_man   = total_day_man ÷ monthly_work_days
```

### 4.2 AI Agent 协同总工作日

| 产出模块 | 公式 |
|---------|------|
| 课程大纲编制 | ai_outline = 0.5 |
| 全部案例代码开发 | ai_code = case_count × 1.0 |
| 全部实验指导书撰写 | ai_doc = case_count × 1.0 |
| 全量知识点知识图谱 | ai_graph = 0.5 |
| 题库出题 + 审核 | ai_question = question_total ÷ ai_review_question_per_day |

```
total_day_ai    = ai_outline + ai_code + ai_doc + ai_graph + ai_question
man_month_ai    = total_day_ai ÷ monthly_work_days
```

### 4.3 对比指标公式

```
save_days   = total_day_man - total_day_ai
save_months = man_month_man - man_month_ai
save_rate   = (save_days ÷ total_day_man) × 100
```

---

## 五、输入校验规则

- `total_class_hour`、`case_count` 必须为正整数
- 若输入 ≤ 0、小数或非数字内容，返回报错：**「输入非法，请重新提供大于 0 的整数：课时、案例数量」**
- 无上限限制，支持大批量课程测算

### 调用格式示例

```
输入：课时 32，案例 8
输入：total_class_hour=32, case_count=8
输入：52课时，10个案例
```
