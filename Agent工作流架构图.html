6 步流程 + 串并行

  • • Step1 解析 + spec 自校验(fail-fast)
  • • Step2 知识图谱 ‖ 大纲（并行）
  • • Step3 lab-guide → quiz（强制串行，编程题取材实验）
  • • Step4 内容审核 → Step5 质量评级 → Step6 整合输出

错误恢复与检查点

  • • 错误分级：parse / runtime / consistency / quality
  • • 断点恢复：run-state.yaml 每步落盘，从断点续跑
  • • 定向回退：按 failed_items 只重做目标 Agent + 下游
  • • CP-1(可选) · CP-2(解析失败) · CP-3(2轮仍C/D) 人工介入

上下文契约 (防压缩)

  • • 磁盘交接，管家只持 agent_result 摘要
  • • 子 Agent 只读最小必需输入文件
  • • 批量生成每门课完成即清理中间摘要
  • • 跨课程仅共享 Memory，不携带产出正文
