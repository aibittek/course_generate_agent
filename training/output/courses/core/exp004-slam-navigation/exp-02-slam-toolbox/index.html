SLAM Toolbox 建图

这节课是整门课的第一个"高光时刻"——你将用键盘遥控小车在房间里逛一圈，然后得到一张跟户型图一样的二维地图。全程只做三件事：启动建图 → 遥控逛圈 → 保存地图。

难度 ⭐⭐ · 4 学时 SLAM Toolbox扫描匹配 回环检测map_saver

01问题引入：怎么把房间"扫"成一张图

EXP-01 里我们知道雷达每 0.1 秒扫一圈，可一圈只看到"眼前一环"。要把整个房间拼成一张图，小车必须边走边拼，而拼图本身又有两个麻烦：

1手推购物车走一圈回原点，因打滑"记的步数"和实际走的对不上——起点终点接不拢
2每圈扫描都要和上一圈对齐（前端扫描配准），错一点，越拼越歪
3逛回出发点时"咦，这面墙刚才见过"——回环检测：把首尾接上，一键把累积误差摊平
4SLAM Toolbox 把这三步做成了现成节点：你只管启动、逛圈、存图
💡 一句话读懂这节课是整门课的第一个"高光时刻"——你将用键盘遥控小车在房间里逛一圈，然后得到一张跟户型图一样的二维地图。全程只做三件事：启动建图 → 遥控逛圈 → 保存地图。

02原理通俗讲解：前端配准与回环

🧩 拼撕碎的地图把户型图撕成 360 张碎纸叠在一起（每 0.1 秒一张扫描），最后只留一小叠（关键帧）。每次拿新碎纸和上一张对齐——这叫前端扫描配准（像玩"大家来找茬"：平移旋转着挪，直到两张图严丝合缝）。等你逛回起点，发现最后一张和第一张原本就是同一面墙——这叫回环检测，把整叠地图"首尾一捋"，之前累计的手抖全被摊平。地图从"歪扭"变"方正"，靠的就是这一捋。
前端
Scan Matching 扫描配准

在 ±0.5 m、±0.01 m 精度的搜索空间里微调位姿，让新一帧扫描与当前地图最吻合（correlation_search_space_dimension 0.5）。

后端
Ceres 图优化

把关键帧当节点、匹配与回环当边，用 LEVENBERG_MARQUARDT 求解器整体调位置，误差被摊到每一条边上。

回环
Loop Closure

回到旧地_RC：在 ±8 m 大范围搜索（loop_search_space_dimension 8.0），精细匹配度过 0.45 响应阈值才认账，防"认错墙"。

关键帧
不是每帧都存

走超 0.01 m 或转超 0.02 rad 才开新关键帧——存太密图臃肿算不动，存太疏拼不上。

频率
地图 10 Hz 刷新

mode: mapping，map_update_interval 0.1 s：RViz 里能看到地图"实时长出来"。

量程
max_laser_range 12.0

与 COIN-D6 雷达一致；超范围的点直接丢弃，避免把无关远处噪声当地标。

03关联知识点

知识点 1
位姿图

关键帧节点 + 约束边构成的图，SLAM 后端优化的就是它；回环边是"首尾相接"的那根超强约束。

知识点 2
odom → base_footprint

建图期间 TF 链：map→odom 由 slam_toolbox 发，odom→base_footprint 由轮式里程计（EKF）发，缺一不可。

知识点 3
map 文件二件套

.pgm 是像素图片（255 空闲 / 0 墙 / 205 未知），.yaml 记分辨率 0.05、origin 原点、阈值——成对才能被 Nav2 加载。

知识点 4
QoS 匹配

/scan 是 Best Effort（尽力而为）：订阅端若用 Reliable 会收不到数据，rviz 里订阅 QoS 要改成 Best Effort。

知识点 5
launch 延迟启动

TimerAction period=10.0：等底盘与雷达先"热身"10 秒再起 slam，避免开机瞬间 TF 不全报错。

知识点 6
好地图四标准

墙单线（厚 < 0.1 m）、尺寸误差 < 2%、四角直角 ≈90°、闭环处无错位。地图不过关，导航全白搭。

04实验目标

  • 跑通 slam.launch.py 建图节点，RViz 中地图随遥控实时生长
  • 用 slam_teleop（w/s/a/d/空格，0.2 m/s、0.5 rad/s）遥控逛完整圈并完成闭环
  • 用 map_save / map_saver_cli 保存出 map_01.pgm + map_01.yaml
  • 按四标准验收地图：墙单线、尺寸 < 2%、直角、闭环错位 < 0.1 m
  • 会诊断 5 类常见问题：QoS、地图不更新、双墙、回环不触发、保存失败

05实验环境与准备

项目要求
系统Ubuntu 22.04 + ROS2 Humble，car1_slam 功能包已编译（含 slam/teleop/map_save 节点与 launch）
硬件小车 C1 满电（逛圈耗电）、COIN-D6 雷（/scan 10 Hz Best Effort）、平整 3 m × 3 m 以上场地
参数文件slam.yaml（mode: mapping、do_loop_closing: true、max_laser_range: 12.0）

RViz 配置Fixed Frame = map，加 Map（/map）+ LaserScan（/scan，QoS 选 Best Effort）+ TF
💡 关键参数速记resolution 0.05 · map_update_interval 0.1 · minimum_travel_distance 0.01 · minimum_travel_heading 0.02 · loop_search_space_dimension 8.0 · loop_match_minimum_response_fine 0.45。

08实操步骤：启动 → 逛圈 → 存图

1终端 1：source 后启动建图（launch 内置 10 秒 TimerAction 延迟起 slam 节点）
2终端 2：启动键盘遥控；RViz 确认 Fixed Frame = map、/scan 点云随车移动
3慢速逛完整圈回到出发点，看到回环连线跳动、双墙合一后，先存图再停车
# ① 启动 SLAM 建图（含 rviz 与 10 秒延迟）
ros2 launch car1_slam slam.launch.py

# ② 另开终端：键盘遥控（w/s 前后 0.2m/s，a/d 转向 0.5rad/s，空格停）
ros2 run car1_slam slam_teleop

# ③ 逛圈前自检：雷达 10Hz、里程计 TF 正常
ros2 topic hz /scan
ros2 run tf2_ros tf2_echo odom base_footprint

# ④ 保存地图（推荐方式一；逛完圈再执行！）
ros2 run car1_slam map_save map_01

# 方式二：nav2 官方 CLI（transient_local 才能收到 latched 的 /map）
ros2 run nav2_map_server map_saver_cli -f map_01 \
  --ros-args -p map_subscribe_transient_local:=true

# ⑤ 停掉遥控（Ctrl+C 前先保存）
pkill -f slam_teleop

保存产物 map_01.yaml 关键字段：image: map_01.pgm · mode: trinary · resolution: 0.05 · origin: [-0.381, -0.482, 0.0] · occupied_thresh: 0.65 · free_thresh: 0.25。

09重点与易错点

⚠️ 重点回环是建图质量的分水岭：走大圈 + 回到起点多停 2 秒，给系统一次"认出老家"的机会。验收时量闭环处——两段墙必须并成单线，错位 < 0.1 m、航向差 < 5°。
⚠️ 常见坑现象 → 解法
RViz 无扫描点LaserScan 空白 → QoS Reliability 改 Best Effort（雷达即尽力而为）
地图不生长/map 不更新 → 确认 slam 节点在跑（ros2 node list）且 /scan 有数据
墙出现双影回环没触发/配准失败 → 降低车速、走规则大圈、回起点停一停再看
回环永不触发闭环区域特征太弱或太快掠过 → 回起点减速正对原方向；检查 do_loop_closing: true
保存失败map_saver 等不到 /map → 加 -p map_subscribe_transient_local:=true，或用 car1_slam 的 map_save
文件名踩坑路径含中文/空格 → 改英文文件名，先保存再 Ctrl+C
  • 地图墙厚 < 0.1 m 单线、整体尺寸误差 < 2%、四角直角 90°±2°
  • 回到起点处 闭环无错位（< 0.1 m / 航向 < 5°）
  • map_01.pgm + map_01.yaml 成对存在，origin/thresholds 齐全
  • 逛圈全程 低速（≤1.0 rad/s 转向）、先存图后停车、电量充足

10总结与思考

✅ 完成成果
一张可用的户型图

slam.launch + slam_teleop 逛圈，map_save 产出 map_01.pgm/yaml 通过四标准验收。

🧠 原理收获
前端 + 后端 + 回环

扫描配准堆关键帧，Ceres 图优化摊误差，回环检测是"一捋正"的关键。

🛠 技能收获
三步操作肌肉记忆

启动 → 遥控逛圈 → 保存；map_saver_cli 的 transient_local 参数套路。

❓ 排障思路
双墙排查链

QoS → /scan 频率 → 车速 → 闭环 → do_loop_closing 参数，逐级定位。
