- 源依据：`courses/sheet1/arm_practice/EXP005_lab_guide.md`（案例、参数、行级出处均经 grep 核对；含讲义勘误口径）

## 设计原则

1. **原理 ↔ 案例一一对应**：每个模块只讲一条原理线，配且仅配一个讲义真实案例（含数值与出处行），案例先出、原理后讲、演示居中。
2. **晦涩即交互**：凡不能"一眼看懂"的概念（坐标变换、余弦定理 IK、插值时序、下探深度、HSV 阈值），必配可拖动/可滑块的演示，参数变化即时反映到图形与公式数值。
3. **数学可把玩**：坐标变换（4×4 矩阵随滑块联动）、运动学（PWM→rad→FK→IK→闭环误差 mm）、轨迹（q(t) 曲线与 PWM 安全边界）均给出"公式逐项 = 滑块读数"的对应关系。
4. **3D 用最简结构**：three.js 只建"能说明问题"的简化五连杆 + 夹爪 + 物块 + 桌面；结构、姿态、抓取过程三类展示齐全，不追求外观还原。
5. **与实验页双向衔接**：每模块底部 `linkrow` 指向实验页真实锚点（已验证 `#s6/#s7/#s8` 存在）；首页新增入口板块反向指入。

## 模块一览（教学目标 · 案例 · 可视化/交互方案 · 衔接）

### M1 · 坐标系与 TF 变换链
- **教学目标**：同一空间点在 `base_link` 与 `camera_depth_optical_frame` 的两套读数互换；读懂 4×4 齐次变换乘点；理解 REP-103 轴向差异与外参误差→系统性抓取偏移的机理。
- **案例**：EXP-07 讲义步骤4——相机系 (0, 0, 0.5) → base_link (0.55, 0, 0.40)；EXP-06 set_pick_target 必须写 `frame_id:'base_link'`。
- **可视化/交互**：TF 树路径高亮（base_link⇄camera 链逐跳高亮）；外参滑块 γ/tₓ/t_z/前向距离/偏角 → 俯视+侧视双面板实时重投影；旋转矩阵与平移向量数值联动；预设按钮一键复现讲义例子。
- **衔接**：EXP-01 §06 TF 坐标树动画、§07 关节限位试算台；EXP-06 §08 实操；EXP-07 §08 服务触发。

### M2 · 正运动学 FK
- **教学目标**：建立"关节角→末端坐标"唯一确定映射的直觉；PWM↔rad 换算肌肉记忆；会用 2R 简化模型（L1=0.105 / L2=0.180 / d=0.085，与 EXP-04 试算台同口径）手算并与代码互验。
- **案例**：EXP-02/05 安全红线"抓取前先预演"——`pwm_to_fk_demo.py` 输入五路脉宽 2150 1200 2200 2275 1500（讲义实验5 步骤2）。
- **可视化/交互**：5 路 PWM 滑块（500~2500）→ 实时换算弧度并逐项代入公式；俯视 x-y + 侧视 r-z 双画布连杆图；r_max=0.4m 参考圈判达；安全区红绿徽章。
- **衔接**：EXP-04 §07 FK 试算台、§08 实操；EXP-02 §07 弧度换算器。

### M3 · 逆运动学 IK
- **教学目标**：三段式解析法（q₁ 指向、2R 余弦定理、pitch 补偿的前两段）；多解（肘上/下）与不可达几何判据；IK→FK 闭环验证意识；DLS 阻尼 λ 的作用。
- **案例**：EXP-06 步骤1——`set_pick_target (0.28, 0, 0.10)`、四元数 {0,1,0,0}（pitch 180°）。
- **可视化/交互**：侧视工作平面**可拖拽目标点**；肘姿切换看两套解；余弦定理逐步代入数值；一键"喂回 FK"显示闭环误差 mm（自检 0.0000mm）；asin 偏置开关联动 q₁；附加 2R 平面 DLS 迭代动画（λ 滑块 0.01~1，观察振荡/过慢/收敛）。
- **衔接**：EXP-04 §06 动画、§08 解析 vs DLS 实操；EXP-05 §08 --direct 实机验证。

### M4 · 轨迹与分步移动
- **教学目标**：轨迹 = q(t)；插值语义（线性/平滑）与分时下发；软限位与 PWM 安全边界（±135° ↔ 500/2500μs 的数值巧合亲测）。
- **案例**：EXP-06 知识点 6.1.3 `_move_stepwise()`——J1 偏转 >0.05rad 时先单动 J1 占 40% 时长、J2–J5 占 60%；EXP-03 YAML 逐行回放同理。
- **可视化/交互**：q(t) 示波器（起终点/时长/分步开关/平滑开关/限位开关六滑块一组）；t 指针播放 + 俯视偏航线、侧视大臂同步动画；PWM 实时换算越界红警；可故意关掉分步看"横甩"。
- **衔接**：EXP-03 §08 回放实操；EXP-06 §06 六阶段动画；M5。

### M5 · 六阶段抓取 · three.js 3D 实验台（核心，需求项）
- **教学目标**：认识简化五连杆结构与关节转轴（TF 三色轴开关）；按讲义六步走完 pick 序列；把 `gripper_depth`、`pre_grasp_height` 变成看得见的高度差；目睹 IK 对工作空间外目标的拒绝。
- **案例**：EXP-06 知识点 6.3.2 `_execute_pick()` 六步：开爪→移到 z+pre_h→下探 z−gripper_depth→合爪→退回 z+pre_h→移到 post_grasp_pose；目标 (0.28,0,0.10)、放置点 (0.059,0.074,0.219)；节点默认 gripper_depth=0.0 / pre_grasp_height=0.03（注：lift_height 声明未用，讲义勘误口径）。
- **可视化/交互**：three.js 场景（桌面 grid、五连杆、开合夹爪、随检测面高度伸缩的红块、放置点 ghost）；**结构模式** 3 关节滑块 + 预设姿态（真机 work 位 / 展平 / 案例 IK 解）+ 坐标轴开关；**抓取模式** 六阶段按钮/自动播放 + gripper_depth/pre_grasp_height/目标 xyz 五滑块，逐帧关节空间插值动画、阶段高亮、TCP 读数与四元数说明、不可达红警；OrbitControls 旋转缩放；WebGL 不可用时优雅降级提示。
- **衔接**：EXP-06 §06/§07/§08；EXP-01 §08 URDF 联动。

### M6 · 视觉定位三件套
- **教学目标**：HSV 抗光照原理与阈值调参；针孔反投影 X=(u−cx)d/fx；TF 桥接进 base_link——"看见即定位"的完整链。
- **案例**：EXP-07——红色两段阈值 [0,100,80]~[15,255,255]∪[160,100,80]~[180,255,255]（launch 实参核对）、fx=fy=614/cx=320/cy=240、深度 uint16 mm÷1000、OBSERVE<1s / PICK<8s / 成功率>85% 性能基线。
- **可视化/交互**：合成场景实时 inRange 掩膜（H 上限/S/V 三组滑块 + 副段联动 + 质心十字）；点击场景任意像素拾取 (u,v)，d/fx 滑块驱动反投影与 TF 到 base_link，俯视画布画落点；故障演练（阈值过紧丢目标、过松混入橙块）。
- **衔接**：EXP-07 §06 三乐章动画、§07 HSV 调参台、§08 端到端；回链 M1、M5。

# 专题二：标定（课程收尾 · 五个部分 s1~s5 · 首页位于第 3 章之后）

- 载体页面：`calibration/index.html`（单文件 HTML，风格与原理实验室一致）；首页入口以**第三章同款卡片版式**（sec-head + grid + card + 五条 explist）插在第 3 章网格之后、TECH STACK 之前。
- 五个部分（用户定稿）：**① 机械臂零位标定 → ② TCP 标定（四点法）→ ③ 相机内参标定 → ④ 手眼标定 → ⑤ 抓取验证**（页面锚点 `#s1`~`#s5`）。
- 范围约定：TCP 改用**四点法**纳入正式教学（尖笔+图钉+纸即可，无需精密量具——修订：原"TCP 不展开"由此推翻）；深度校正作为手眼同会话免费副产物在部分 4 带过；杆长/装配级几何标定仍不展开流程，仅在部分 5 以 test_fk_ik 闭环复核把关。
- 统一叙事：M1~M6 抓取链每一环都有出厂偏置，标定 = 逐层测出并减掉；症状先归四象限（电零位/光学内参/空间外参/运动学几何），再对号入座。

### 部分 1 · 机械臂零位标定（电零位 · `#s1`）
- **教学目标**：理解电中位≠机械中位；跑通 servo_calib 五步；明白 offset 生效边界；掌握粗调→精调与 .bak 回滚。
- **案例**：`calibration/servo_calib_gui.py` + `servo_offsets.yaml`（offset=当前PWM−1500）；讲义实验3 步骤3c（含坑表）。
- **交互**：J2/J3 零位偏移滑块（±120μs→角度换算×0.002356）→ 侧视"指令目标（蓝虚）vs 实际姿态（红实）"对比，Apply 校准一键对齐 + 归零验证文案。
- **关键代码事实**：servo_offsets.yaml 仅 calibration 包自读写，**arm 控制链不自动加载**——以 joint_command 归零验证为准（页内"生效边界"提示）。
- **衔接**：EXP-03 §08/§10；顺序约束：部分 1 必须先于部分 4（手眼）与部分 2（四点法依赖 FK 准）。

### 部分 2 · TCP 标定（四点法 · 新增 · `#s2`）
- **教学目标**：理解 TCP=法兰之后的等效工具点，不标=换姿态画圆；掌握四点法（≥4 姿态顶同一尖点）原理、最小二乘解算与弥散验收；看懂 FINGERTIP_OFFSET_Z=0.033、Y_TCP=0.215mm、TCP_OFFSET_Z=0.0762 的来历。
- **案例**：`kinematics/config.py`（LEVEL3_SUMMARY 称其 "Robot Calibration Parameters"）+ TESTING_GUIDE"指尖位于 tcp_link 下方 33mm"；讲义实验5 标定工具清单（刻度标定尺、水平仪）；呼应 EXP-06 gripper_depth=-0.033"负值=抬高"。
- **五步流程**：装尖点 → ≥4 明显不同姿态顶同一图钉孔 → FK 得 p_i/R_i → 解 p_i+R_i·t=c 消 c 最小二乘 → 换任意姿态复顶验弥散。
- **交互**：法兰圆半径（四姿态张角）/ 真实 Δz / 你标定的 Δz′ 三滑块 → 四红叉绕真实尖点画圆（半径=|Δz′−Δz|，mm 直读）；"四点法求解"一键对齐塌缩；io 展示 |p_i+R_i·t_used−c| 恒为常数、方向随姿态转的机理。
- **衔接**：EXP-06 §07（gripper_depth 与 0.033）；原理 M5/M3；前置部分 1。

### 部分 3 · 相机内参标定（光学内参 · `#s3`）
- **教学目标**：读懂 K 矩阵物理含义；判断何时必须重标；会算"Δfx → 抓取点偏几毫米"。
- **案例**：HP60C 出厂 K=[614,0,320;0,614,240] + PLUMB_BOB（`CameraPublisher.cpp`）；`camera_info` echo 读法；AprilTag PnP 用畸变系数。
- **交互**：针孔俯视图 + Δfx（±90）/距离/像素偏心三滑块 → 真值 X 与误用 X′ 双射线落点 + 0.3/0.6/1.0m 三档偏差表（mm 直读，验证线性放大规律）。
- **重标时机**：跌落/镜头松动/对焦变/出图分辨率变；方法论=棋盘格+camera_calibration（概念层，本车 K 为出厂值只读+复核）。
- **衔接**：原理 M6；EXP-07 §07。

### 部分 4 · 手眼标定 AX=XB（空间外参 · 重点 · `#s4`）
- **教学目标**：X=T_cam_ee 的含义与方程来源；14 姿态设计原则；采集→求解→验证→接入四步全流程；知道"未接入就白标"的坑。
- **案例**：`eye_hand_calibration` 全链——`calibration_poses.yaml`（14 位姿、三档 pitch、旋转覆盖>60°、相邻>15°、ALL_PAIRS、最小旋转 8°、有效≥10）、`hand_eye_solver.py`（A=T_ee 相对、B=T_tag_cam 相对、Tsai-Lenz/Horaud）、`verify_calibration`（pass_threshold_mm=5.0）、讲义实验7 步骤4"当前未接入"警告。
- **交互①**：位姿数 n（2~14）+ 旋转覆盖（5~90°）滑块 → ALL_PAIRS 配对数 n(n−1)/2 实时计算 + 条件评分与判定；双姿态示意画布 + "播放配对"动画（A 臂端相对运动 / B tag 视觉相对变化 / X 腕→相机）。
- **交互②（免费副产物）**：深度 d_corr=scale·d_raw+offset 双滑块 → 残差曲线 + 卷尺三点表（0.3/0.5/1.0m），呼应讲义 ±2~3cm@1m 基线。
- **接入两条路**：X 发静态 TF 替换 URDF 相机 joint；深度校正 apply_correction + 话题 remap。
- **衔接**：原理 M1；EXP-07 §08；前置部分 1（零位）+ 部分 3（内参，PnP 依赖）。

### 部分 5 · 抓取验证（`#s5`）
- **教学目标**：把 残余<1°、尖点重合、K=614 远端一致、5mm、>85% 串成依赖有序的五项验收链——顺序不可倒。
- **交互**：五项可勾选验收清单（依赖顺序 ①零位复核 joint_command 全零→②TCP 复验+test_fk_ik 闭环把关→③内参+深度抽查（近中远三点，远端先偏即回部分 3）→④手眼 verify<5mm+接入确认→⑤真机基线 OBSERVE<1s/PICK<8s/>85% 100 次）→ 进度条 + 全绿结论卡；附"何时重标哪一部分"速查表（换工具→TCP / 摔相机→内参 / 支架动→手眼 / 搬底座→只复核）。
- **频率建议**：常规周抽测①+⑤；学期初/设备动过跑②③④全链。
- **归因纪律**：⑤ 失败先回看①~④哪个绿勾勉强过，再分视觉/IK/抓取三类。
- **衔接**：EXP-05 §08（② 执行处）、EXP-07 §08（⑤ 执行处）；全部衔接锚点 `#s6/#s7/#s8/#s10` 已 grep 验证存在于对应实验页。
