四步看懂"磁铁转、芯片知道角度"：① 位置 → ② 霍尔效应（磁场变电压）→ ③ 两根元件测分量 → ④ atan2 算角度（往下拖磁铁试）
① 位置：磁铁（红 N / 蓝 S）贴在轴尾跟轴一起转；芯片隔空固定不动。磁铁周围有一圈看不见的磁场，磁铁转，磁场方向就跟着转。
② 霍尔效应（磁场怎么变成电）：芯片里有一小片通电的霍尔元件。电流本来直着走，磁场穿过时把电荷往一边推，于是片子两边一边电子多、一边电子少，冒出一个电压——磁场越强、推得越狠，电压越大。磁场就这样被翻译成了电信号。
③ 一个元件只能测一个方向，所以要两根：单个霍尔片只对"垂直它的那个磁场方向"敏感，测不到另一方向。芯片里 X、Y 两根互相垂直：磁铁转到 θ，X 读 cosθ、Y 读 sinθ。
角度 θ 60°
// 芯片解码：两分量 → atan2：
Bx = cos60° = 0.500　By = sin60° = 0.866 → atan2(By,Bx) = 60.0°
④ 结算：拿到 Bx、By，用 atan2 一算就回到角度——方向就这样变成了度数。
绝对式：转到哪读到哪，断电也记得住位置，不用从头数圈。磁铁不碰芯片，不磨损、耐脏。
