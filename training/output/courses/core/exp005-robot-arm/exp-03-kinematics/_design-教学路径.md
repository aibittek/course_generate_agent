# EXP-03 正运动学 · 教学路径设计（v2 讨论稿）

> 目标（唯一）：**给定 5 个关节角，算出指尖 tcp_link 的位置和姿态。**
> 所有内容都为这一句话服务，凡是与它无关的都不进主线。

---

## 一、先回答“数学到底要多少”

用户问得很准：目标字面上就包含了三角函数、姿态表示、坐标变换、矩阵。逐一判定：

| 数学工具 | 是否跑得掉 | 为什么 | 在本课的角色 |
|---|---|---|---|
| **sin / cos** | 跑不掉 | “斜着伸"必须用;而且**关节角本来就是角度** | 主线第 1 步 |
| **向量**（分量、加法） | 跑不掉 | 一次"伸一段"就是向量相加；x/y/z 三个分量 | 主线第 2 步 |
| **矩阵** | 跑不掉 | 连续多次"转+平移"必须能把变换乘起来，否则每节都要重新列式 | 主线第 4 步（只学 2×2 和 3×3 的用法，不推导） |
| **旋转矩阵** | 跑不掉 | 关节转动在数学上就是乘旋转矩阵；也是姿态的自然表示 | 主线第 4 步 |
| **齐次 4×4** | 半跑不掉 | "转 + 平移"合成一次乘法要用到；但**可以先不用，最后再引出** | 主线第 5 步（收尾才上） |
| **欧拉角 / 四元数** | 可暂缓 | 姿态有 3 个角，讲"姿态"时用**欧拉角**（就是 q1~q4 的组合效果）足够；四元数只要一句话"避免万向锁的另一种写法" | 进阶彩蛋 |
| **叉积** | **能跑掉** | 叉积用来判断"绕哪根轴转的方向"（右手定则）。本课转轴是**固定的**（J2/J3/J4 永远绕 Y），所以只在讲“为什么正转是那个方向"时用一次**右手定则的图形说明**，不必写叉积公式 | 一句话 + 一张手图 |
| **点积** | **能跑掉** | 点积用来算夹角/投影；本课不做投影，直接分解到 x/z 分量即可 | 不进主线（可选拓展） |

**结论：主线数学 = 三角函数 + 向量分量 + 2D 旋转矩阵 + 齐次矩阵（最后收）**
叉积只用"右手定则"的直观版；点积、四元数、雅可比全部不进主线。

## 二、讲解路径：七个台阶（每一级只加一个新工具）

设计原则：**先让手算能算，再让矩阵替手算，最后让程序替矩阵。**
每一级都能用上一级的结果去验算，学生每一步都能"对上账"。

### 台阶 0 · 抛出问题（3 分钟，1 张图）
- 图：机械臂 + 桌上的杯子 + 一个问号
- 一句话：**"我想知道，摆成这个姿势，指尖落在哪？"**
- 现场可做的对比：**正运动学（摆好姿势算位置）vs 逆运动学（想去某个位置，反推姿势）**——本课只做前者
- 落到具体数字：默认姿态 q = (0°, −50°, 105°, 35°, 0°) → 指尖 = (0.157, 0, 0.342) m
- **这一级结束时学生应能回答**：我要算的是什么

### 台阶 1 · 一根棍子（三角函数登场）（动画）
- 动画：一根长度 L 的棍子，一根端固定，绕水平轴从竖直（0°）转到平躺（90°）
- 同步显示两个数：**往前的距离 = L·sin θ，往上的距离 = L·cos θ**
- 关键让利：θ=0 时→(0, L)；θ=90° 时→(L, 0)；θ=60° 时→(0.87L, 0.5L)，用具体数字
- 一句话总结：**"斜着伸一段，拆成前后 + 上下两份"**
- 新工具：sin / cos
- 验证题：L=0.126 m，θ=30°，往前多少？（0.063 m）

### 台阶 2 · 谁来定"往前"的方向（航向 / 极坐标）（动画）
- 动画：俯视图，转台转 0°/45°/90°，同一根棍子的落点绕圈
- 引入：第一个关节只负责**转圈**，前两步的 (前, 上) 要再乘一次 sin/cos 才能落到 x-y 平面
- 一句话：**"先算平面内伸多远，再决定朝哪个方向伸"**
- 新工具：向量在水平面里的分解（还是 sin/cos，换了个平面）
- 验证题：把 J1 从 0° 转到 90°，指尖的 x、y 怎么变？（x→0，y→0.157）

### 台阶 3 · 两节串起来：角度会累加（动画 + 一张表）
- 动画：先转大臂 30°，再在小臂上"接着"转 40°——小臂的实际倾角是 **70°**，不是 40°
- 关键认知：**后一节的角度建立在"前一节已经转过去"的基础上**
- 一张表：累计角 = q2、q2+q3、q2+q3+q4
- 这一级结束：**已经可以用计算器把 5 个角一步步算出手算结果了**（还不涉及矩阵）
- 验证题：默认姿态下，工具段的累计角是多少？（−50+105+35 = 90°，正好水平）

### 台阶 4 · 用矩阵把"转"变成"乘"（矩阵登场）（动画 + 对照表）
- 动机（必须讲透）：三段都要算 sin/cos、每段公式都不一样，**换个顺序就重写一遍**。能不能写成一个固定模板，套数字就行？
- 2×2 旋转矩阵：一行动画演示"一个点乘上这个矩阵，就等于绕原点转了 θ"
- 对照表：左边手算三步，右边一次矩阵乘法，**结果完全相同**
- 新工具：**矩阵 = 一排公式的打包**，不是新数学
- 说明姿态：3×3 矩阵的**列**就是"物体自己的三根轴"在空间里的方向 → 这就是"姿态"的数学表示（欧拉角是另一种读法）

### 台阶 5 · 转完还要平移：齐次矩阵（4×4）（动画）
- 痛点动画：只有旋转矩阵时，"转完再挪一段"需要写两次运算；4×4 一次搞定
- 讲法：4×4 的左上 3×3 是旋转，最后一列是平移，最后一行 (0,0,0,1) 只是占位
- 一句话：**"4×4 = 姿态 + 位置 打包成一个可乘的东西"**
- 到这里：**一节机械臂 = 一串 4×4 相乘**，这是所有机器人库（ROS、urdf-loader）内部干的事
- 可选：给出 simple-arm 的 5 个 4×4（用 numbers 显示，不过度推导）

### 台阶 6 · 回到真机：为什么它其实"不算标准 DH"（对照表）
- 三栏对照：手算 / 齐次矩阵 / URDF 直接算 —— 三者结果完全一致（有数值验证）
- 说明：本机**满足 DH 的前提**（轴平行或垂直、无横向偏置），但 URDF 写的是"关节链"，DH 参数需要另外推一张表；**不推也能算**，这就是 ROS 的做法
- 一句话：DH 是一种**简化书写**的约定，不是必经之路
- 进阶彩蛋（折叠）：欧拉角 vs 四元数 / 雅可比 / 叉积的用途

### 台阶 7 · 上机验证（实操，不进原理主线）
- 跑脚本、改角度、核对页面读数、三个验收点
