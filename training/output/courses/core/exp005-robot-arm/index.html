SAFETY FIRST

动手前的四条安全红线

机械臂是全课程唯一会"真动"的执行器，越界代价是舵机堵转打齿、甚至拽倒自身。以下红线在每个实验第 09 节还会以坑表形式复现。

  1. PWM 一律落在 500~2500 μs 之内——发之前先心算对应角度，超限即撞机械限位。
  2. 目标位姿必须逐步逼近——先小步试、再放大步长，禁止一条指令甩到极限位。
  3. 抓取前先预演——用 pwm_to_fk_demo 或 Web 仿真器把 5 路 PWM 走一遍，确认不会撞桌再上真机。
  4. 先跑安全前置脚本——test_servo_direct 自检通过、串口权限（dialout 组）配好，才允许进入交互模式。
LEARNING PATH

学习路径建议

先比喻，后公式

每个实验的"原理通俗讲解"先用生活类比（手臂、暗号脉宽、反推姿势）建立直觉，再看 DH 表与 CRC8 —— 按顺序读，公式不再是天书。

软硬两条路线对照

EXP-01 是纯仿真路线，EXP-02 是裸机串口路线，EXP-03 回到 ROS2 架构路线 —— 同一条机械臂三种打开方式，对照着学最快。

动画与互动台先玩一遍

帧格式、连杆几何、抓取流程都有 SVG 动画；PWM↔弧度、FK 正解、HSV 调参都有互动台 —— 先玩懂参数，再上实机少翻车。

安全红线贯穿始终

PWM 必须落在 500~2500μs、目标须逐步逼近、抓取前先预演 —— 实机代价是堵转打齿，把第 09 节的坑表背下来再动手。

LEARNING OUTCOMES

学完你将能做什么

四个可验收的能力目标，对应三个篇章的递进路径——每一条都能在实验报告里拿出证据。

读得懂模型

看 URDF 就知道每个 link / joint 在干什么，能沿 7 坐标系 TF 链回答"末端到底在哪"，能在 RViz2 里复现并修改模型。

组得出协议帧

用 pyserial 手工拼出 0xAA55 + CRC8 的完整帧，把任意关节角换算成 500~2500 μs 安全脉宽并下发真实舵机。

算得对运动学

手算与代码双轨完成 FK 正解与解析 IK 逆解，会跑闭环验证、对照 Avg<0.5 / Max<1.5 mm 验收线，并按讲义口径归因误差（当前 18~23 mm 超差源于 IK/FK 模型不一致，而非机械偏移）。

调得动抓取

调 gripper_depth / pre_grasp_height 等节点参数，串起"预演 → 设目标 → Trigger 抓取 → 放置"全流程，并能扩展到视觉动态抓取。

COURSE MAP

七步学习路线图

把 7 个实验串成一条通关路线，每一步都踩在上一步的成果之上。

  1. STEP 1 · EXP-01 仿真建模（4 学时） 在 RViz2 / Gazebo 里"造出"机械臂，弄清 7 个坐标系与每个关节的转轴方向。
  2. STEP 2 · EXP-02 串口与 PWM 底层（4 学时） 绕开 ROS2 直连下位机，亲手组 0xAA55 + CRC8 帧，把角度变成舵机能听懂的脉宽。
  3. STEP 3 · EXP-04 正/逆运动学基础（4 学时） 建立"关节角 ↔ 末端坐标"的几何直觉，DH 表、FK 变换链与解析/数值两路 IK 对比。
  4. STEP 4 · EXP-05 逆运动学解算（4 学时） 跑 test_fk_ik 闭环验证解算器，按实测口径归因误差（当前 3/4 点位 FAIL、18~23 mm，疑为 IK/FK 模型不一致），--direct 实机逼近。
  5. STEP 5 · EXP-03 ROS2 架构与动作回放（4 学时） 勘察 bringup 节点拓扑，让 action_player 把 pick_and_place.yaml 里的动作原样演一遍。
  6. STEP 6 · EXP-06 逆运动学固定抓取（4 学时） 预演 → set_pick_target → Trigger 六阶段抓取，调节 gripper_depth / pre_grasp_height 适配不同物体。
  7. STEP 7 · EXP-07 视觉动态抓取（8 学时） HSV + 深度反投影 + TF 三件套定位任意摆放的目标，五状态机一键完成"看见即抓起"。

FAQ

开课前的三个常见疑问

没有真机能学完吗？

能。EXP-01/04/05 全程可用 Gazebo 与 Web 仿真器完成闭环验证；EXP-02/03/06/07 的命令与协议推导可在无硬件条件下通读演练，上机步骤以真机验收为准。

为什么先仿真、后裸机？

仿真里改坏一个 URDF 只是重载，裸机发错一帧可能堵转。先在数字世界建立"关节角 ↔ 末端位置"的直觉，再下探串口与 PWM，翻车成本最低。

数学基础差怎么办？

只需三角函数与二维向量：FK=逐段累加旋转平移，IK=解一个含 sin/cos 的方程组。第 06 节动画负责建几何直觉，第 07 节互动台负责代数验算，公式不背也能算对。
