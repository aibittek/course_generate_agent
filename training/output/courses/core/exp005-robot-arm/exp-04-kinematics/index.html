EXP-04 · 第 2 章 · 验证性 · 4 学时

正/逆运动学基础

在浏览器里的 3D 仿真器上，弄懂机械臂最核心的一对问答：已知各关节角，指尖在哪（正运动学 FK）；想让指尖到哪，各关节该弯多少（逆运动学 IK）。解析法与 DLS 数值法同台对比，用 DH 参数表和闭环误差给自己交一份可量化的答卷。

⭐⭐ · FK / IK · Web 仿真器

01问题引入

前三个实验里，你已经能让机械臂"动起来"：URDF 描述它的身体，串口协议驱动它的舵机，action_player 回放它的动作。但一直有一个绕不开的幕后主角——运动学。你往 /arm/target_pose 发一个坐标 (0.28, 0, 0.10)，控制器凭什么算出五路 PWM？你在 Web 仿真器里把目标球拖到 (0.15, 0, 0.25)，页面凭什么瞬间把小臂折成对应姿态？

本质上，机械臂每天都在回答两个问题：

  • 正运动学（FK）：已知五个关节角，指尖究竟在空间哪个点？——"弯完胳膊，看指尖到哪了"。
  • 逆运动学（IK）：想把指尖放到那个点，五个关节角各应该是多少？——"看到杯子，反推胳膊怎么弯"。

本实验不下放实机指令，全部在 server_cors.py 起的 Web 仿真器里完成：浏览器本地跑 FK/IK 库，拖一拖目标球、改一改关节角，把这两问一直答到闭环误差小于 1mm。

02原理通俗讲解

正运动学 = 盯着自己的手臂算指尖。像你闭着眼把胳膊摆成某个姿势，让朋友量指尖离地多高：只要知道大臂多长、小臂多长、每个关节弯了多少度，一路"接力"算过去就能得到指尖位置。机械臂的每节连杆都有一张"臂长名片"——DH 参数，把名片首尾相乘（齐次变换矩阵连乘），FK 就算完了。

逆运动学 = 想拿桌角的杯子，反推胳膊怎么弯。这更难：指尖目标只有一个点，关节角却有五个，答案往往不止一种（胳膊从上方探和从下方探都能到）。生活直觉也告诉你：IK 不唯一、有时无解（杯子太远够不着）、有时难算（胳膊伸到笔直的"极限姿势"附近特别别扭）。

解析法 IK
几何作业直接写答案

像初中平面几何：把 5 自由度臂拆成"底座转角 + 2R 平面机构"，用三角函数封闭求解。速度 μs 级、结果确定，car1 的 ik-analytical.js 即此类。

数值法 DLS
闭眼摸象式逐步逼近

每次只朝"误差变小"的方向挪一小步（Δq = Jᵀ(JJᵀ+λ²I)⁻¹e）。阻尼因子 λ（仿真器默认 0.1）像防抖杆：接近奇异时自动减速，宁可慢也不乱抖。

大臂不在底座正中心（d=0.085m）是 car1 的一个几何细节：做 IK 几何推导时要用 asin 补偿这一段偏置，否则算出来的指尖总是差一截。通俗说：别人的胳膊长在肩膀正上方，car1 的"肩膀"和"大臂根"错开了 8.5 厘米，量尺子时别忘了这段。

进阶 · 雅可比与奇异性：为什么手臂"伸直了就动不了"

雅可比矩阵 J 就是"汇率表"：关节转得快慢（q̇）要换算成指尖动得快慢（ẋ），靠的就是 ẋ = J·q̇。J 的每一列回答一个问题——"单独转这个关节，指尖往哪个方向、以多大速度走？"两列方向能"张开"的范围越广，指尖越听使唤。

🖱️ 蓝/紫箭头 = J 的两列换算方向：转关节 1 与 转关节 2 分别把指尖带向哪。β=180°（完全伸直）时两箭头趋于平行——它们"张不开"了，det(J)→0，这就是奇异位：沿臂方向的"汇率"变成 0，指尖再怎么转关节也够不进那个方向；反过来若想让指尖沿臂方向匀速移动，反解出的关节速度 q̇ = J⁻¹ẋ 会趋于无穷——真机上表现为关节突然暴走或报错。本课 DLS 的阻尼因子 λ（仿真器 0.1）就是给奇异位踩的刹车；07 节闭环验证时若某个位姿附近误差诡异，先想想是不是进了奇异区。

04实验目标

  • 能用自己的话向同伴讲清 FK 与 IK 的区别，并说出 car1 为 IK 引入的 d=0.085 asin 补偿缘由。
  • 能启动 Web 仿真器并定位三套核心源码：fk.js、ik-analytical.js、ik-numerical.js，读懂 dh_params.json 每一列含义。
  • 能在仿真器中完成 FK↔IK 闭环验证：目标点 P1=(0.2, 0.1, 0.2) 经 IK→FK 后误差 < 1mm。
  • 能切换解析法与 DLS 数值法，观察奇异位姿下解析法失效而 DLS（λ=0.1）仍收敛的现象。
  • 能用 workspace_scanner 执行球面扫描（r_max=0.4m），得到并解释"可达率"指标。

05实验环境与准备

本实验不需要 ros2 launch，甚至不需要接机械臂——只依赖一个 Python 服务和浏览器，是全课程门槛最低的"纯脑力+可视化"实验。

06动画讲解：关节角叠加，指尖坐标一点点"长"出来

动画 8 秒一循环：θ2、θ3 依次变化，末端点带着坐标沿弧线移动。正解就是"接力赛"——每一级关节角都乘进 4×4 矩阵里，最终位置是五次叠加的结果；改任何一个角，终点都会挪，这正是 FK 的确定性。

07互动讲解：FK 正解试算台 + 闭环误差判定

互动台 · 已知关节角，指尖在哪？（2R 简化，单位 m）
提示：正解用讲义 2R 简化模型（L1=0.105，L2=0.180，底座偏置 d=0.085），完整链以 dh_params.json 为准。误差判定阈值取讲义闭环标准 1mm。

试几组再回网页仿真器对账：把 θ2=0.5、θ3=-1.0 输入页面里的滑块，看浏览器实时 FK 输出的坐标；再到误差判定里输入你的回算值——误差 = √(Δx²+Δy²+Δz²)，小于 1mm 显示 ok，否则标红提醒。这就是讲义"目标点 P1 经 IK→FK 后误差 < 1mm"的白盒版。

09重点与易错点

理解要点：FK 一对一、IK 一对多（或多对零）。仿真器里同一个目标点用 prefer_elbow='up'/'down' 能切出不同构型——这不是 bug，是多解的本来面目；真正判别好坏的是闭环误差与是否踩软限位。
坑现象对策
URL 少了 /viewer页面 404 / 空白必须访问 http://localhost:8000/viewer
8000 端口被占浏览器打不开lsof -i:8000 查占用进程
跨设备访问失败对端无法连接用 hostname -I 查设备 IP，改 http://<IP>:8000/viewer；server_cors.py 已放开 CORS
忽略 d=0.085 偏置手算 FK 与页面差 8cm 级解析推导里必须做 asin 补偿
奇异位姿求解失败解析法报错/跳解切 DLS 数值法，λ=0.1 阻尼兜底；靠近笔直伸展位时尤其注意
可达率看不懂指标忽高忽低先固定 r_max 与采样数再比较；排查顺序 DH → 软限位 → IK 求解器
  • 闭环三连问必做：IK 解出的角喂回 FK，位置误差是否 < 1mm？末端姿态是否贴近目标 pitch？解是否全在软限位内？
  • 做完用 demo_fk_ik.py 离线复核一遍——它和浏览器跑的是同一套数学。

10总结与思考

FK 正解
关节角 → 指尖坐标

DH 表五级矩阵连乘，一对一定论。偏置 d=0.085 别漏。

IK 逆解
指尖目标 → 关节角

解析法快而脆，数值法（DLS, λ=0.1）慢而稳，多解需选择。

闭环验证
IK→FK 误差 < 1mm

P1=(0.2,0.1,0.2) 拖点实测，误差是唯一诚实的裁判。

工作空间
r_max=0.4 球面扫描

可达率是采样口径下的比例，不是体积。

思考题 1：工作空间扫描给出的"可达率"指标有何局限性？如何用"可达体积"更准确地描述机械臂的工作空间？（提示：采样半径、采样密度、内外层分布都会改变这个数字。）
思考题 2：同一个目标点，解析法给出"手肘朝上"、DLS 迭代给出另一个同样达标的解——下游的抓取程序应该按什么标准二选一？把你在 EXP-03 学到的软限位、奇异检测一起考虑进来。
