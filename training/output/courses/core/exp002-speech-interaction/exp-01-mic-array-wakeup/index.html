六麦阵列串口唤醒：机器人耳朵的第一课

本实验回答一个生活问题：你喊"小飞小飞"，机器人怎么知道你在叫它？背后是三件事——六只麦克风靠"时间差"听声辨位、芯片认出自家唤醒词、3 秒冷却防止连声误触发。我们跑通一个 GUI，亲眼看到波束方向随你的位置转动。

难度 ⭐ · 4 学时 六麦阵列 TDOA 波束 唤醒词 · 防抖 pyserial · Tkinter

01问题引入：机器人怎么知道"你在叫它"

对着智能音箱喊一声"小飞小飞"，它灯带一转、应声而答；可要是两个人隔着房间聊天，它却不该随口插嘴。这个"该醒才醒"的问题，拆开是三连问：

1叫没叫？——麦克风时刻都在收音，怎么从嘈杂环境里认出"小飞小飞"这四个字
2谁在叫？——房间里多人说话，怎么判断声音来自哪个方向
3叫了几遍？——一句话尾音会重复触发，怎么避免 1 秒内醒来 5 次
💡 思路这三个问题交给六麦阵列芯片统一解决：它在单片机里实时完成"听声辨位 + 认唤醒词"，一旦命中就通过串口发一条消息给主机。主机只负责读消息、做防抖，不用自己算声学算法——专业的人干专业的事。

02原理通俗讲解：六只耳朵怎么听声辨位

生活比喻：操场上的"听声辨位"。蒙上眼睛听人喊你，你先意识到"有人叫我"，还会下意识转头找方向——单耳判断"有没有"，双耳靠声音到达两耳的时间差判断"在哪边"。六麦阵列就是把这对"耳朵"扩成六只：

1听声辨位 = 六只耳朵对表：6 个麦克风均匀排成一圈，同一句话到达每个麦的时刻略有不同，这个微小时间差就是 TDOA（到达时间差），芯片据此算出声源方向（0~360°）
2唤醒词 = 认自家门铃：芯片提取声音特征，比对内置的"小飞小飞"声纹模板——就像门铃只认自家那声"叮咚"，别人按门铃不开门
3防抖 = 挂门挡：门铃刚响过就挂上门挡（wakeup_lock），3 秒内的重复喊声一律忽略——这就是 3 秒防抖
概念生活类比本实验对应
波束成形把六只耳朵听到的内容"对表合并"，只放大某个方向的声音波束号 0~5 / 角度 0~360°
唤醒词检测（KWS）门铃只认自家叮咚ivw 唤醒事件（"小飞小飞"）
防抖（debounce）挂门挡，短时间内不再响应3 秒冷却 + wakeup_lock
🔍 串口是什么串口（UART）就像一条只允许一个字节一个字节排队通过的窄门：阵列和主机约定好一套"打包规则"，发送方按规则打包、接收方按同样规则拆包，看到消息就知道"机器人醒了"。你不需要懂打包细节，会用 GUI 读结果即可。

03关联知识点

硬件
讯飞 XFM 六麦环形阵列

6 麦克风环形布局，板载唤醒固件，USB 接入工控主机（设备节点 /dev/ttyACM0，波特率 115200）。

算法
TDOA 波束成形

利用声波到达六个麦克风的时间差算出方向，输出波束号与 0~360° 角度。

机制
唤醒词 + 3 秒防抖

芯片认出"小飞小飞"后发 ivw 事件；主机用 wakeup_lock 做 3 秒冷却，避免连声误触发。

04实验目标

  • 接好阵列，用 lsusb 看到 1a86:55d4，确认设备节点 /dev/ttyACM0
  • 运行 xf_mic_array_gui.py，GUI 窗口正常打开
  • 喊"小飞小飞"，看到 [WAKEUP] 日志和波束指针
  • 绕阵列走动，观察波束角度随方位连续变化；1 秒内连喊两次只唤醒一次

05实验环境与准备

# ① 硬件：讯飞 XFM 六麦阵列 → USB 接入工控主机
lsusb | grep -i 1a86
Bus 001 Device 005: ID 1a86:55d4 QinHeng CH340 serial converter

# ② 确认设备节点（可能是 ttyACM0 或 ttyUSB0）
ls -l /dev/ttyACM*
crw-rw---- 1 root dialout 188, 0 ... /dev/ttyACM0

# ③ 安装依赖
pip3 install pyserial
💡 准备清单阵列平放桌面、远离音箱（避免自唤醒）；关闭可能占用串口的串口调试助手；记录你机器上阵列的真实设备号，后续所有命令都以它为准。

08实操步骤：跑 GUI 看波束方向

1接线自检：lsusb 看到 1a86:55d4，/dev/ttyACM0 存在
2运行 GUI：python3 xf_mic_array_gui.py，窗口打开、指针归零
3喊"小飞小飞"：看到 [WAKEUP] 日志、指针指向你所在的方向；绕阵列走动，角度跟着转
# —— 运行 GUI ——
python3 xf_mic_array_gui.py

# 预期日志输出：
# [BEAM] id=4 angle=315°   （手指/身体在左上方向）
# [WAKEUP] beam=4 angle=300°  （喊"小飞小飞"触发唤醒）
# [WAKEUP] 被拦截 —— 距上次唤醒仅 1.0s < 3.0s   （1 秒内连喊第二次）
⚠️ 小贴士阵列平放桌面，人站在 0.5~2 米处正常音量喊即可；不要对着阵列大声吼，反而容易失真。走动时注意观察角度数值连续变化（0~360° 回绕是正常的）。

09重点与易错点

🎯 本实验三重点① 六麦阵列靠 TDOA 时间差听声辨位；② 唤醒词像门铃只认自家叮咚；③ 3 秒防抖 + wakeup_lock 防止连声误触发。把这三件事想通，实验就成功了一半。
⚠️ 常见坑现象 → 解法
权限不足Permission denied: /dev/ttyACM0 → 把自己加入 dialout 组（sudo usermod -aG dialout $USER）后重新登录
设备号漂移重插后 ttyACM0 变 ttyACM1 → 用 ls -l /dev/serial/by-id/ 找稳定软链，别写死设备号
唤醒不触发阵列被遮挡 / 音箱自唤醒干扰 / 唤醒词不对 → 阵列平放、离音箱 1m+，正对阵列正常音量喊"小飞小飞"
  • lsusb 可见 1a86:55d4，GUI 能正常打开
  • 绕阵列走动，[BEAM] 角度随方位连续变化（0~360° 回绕正常）
  • 喊唤醒词出现 [WAKEUP]；1 秒内连喊两次只出一条日志
  • 能用自己的话向同伴讲清"防抖期 = 挂门挡"的类比
