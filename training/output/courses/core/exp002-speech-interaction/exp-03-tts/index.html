EXP-03 · 第 1 章 · 设计性 · 4 学时

TTS 语音合成：让机器人开口说话

机器人听懂了，还得用自然的人声回答。本实验用"打字机→印刷机"的类比，带你理解文字变声音的三步过程，然后动手合成一句话、播放出来、调语速听变化。

难度 ⭐⭐ · 4 学时 文本→音素音素→谱 谱→波形语速控制

01问题引入：只会"听"不会"说"的机器人

前两个实验让机器人能听、能转成文字。但如果它回答时屏幕上只打印一行字——用户就得盯着一台会说话的机器看字幕，交互感瞬间归零。语音输出要解决三个问题：

1读不对："2026年9月24日"该念"二〇二六……"还是"两千零二十六……"？数字、日期要先"正读"
2合成慢：一句 10 秒的话算了 30 秒，对话根本没法进行——合成速度必须跟上语速
3播不对：好不容易合成的语音，从喇叭放出来变成"快放 2 倍"——采样率或声道与硬件不匹配
💡 一句话理解TTS 的任务就是把文字变成声音，而且要快、要清晰、要自然。下面用一个生活类比把它拆成三步。

02原理通俗讲解：从文字到声音的三级跳

生活比喻：打字机 → 印刷机 → 发声器。想象一台老式打字机和印刷机的合作：

1文本变音素 = 打字员查字典：你写了一封信，打字员需要查字典，把每个汉字找到对应的拼音——这一步就是把文字变成音素（发音的基本单位），相当于"查字典"
2音素变谱 = 印刷机排字模：打字员把查好的拼音排成一行行字模，印刷机按字模印出深浅不一的墨点——这一步就是预测每个音的高低和响度（旋律/谱），决定声音的"起伏"
3谱变波形 = 纸带过发声器：印好的纸带快速通过发声器，纸带上的凹凸带动喇叭振动——这一步就是把谱变成真正的声波，让声音真正响起来
概念打字机→印刷机类比TTS 里是什么
文本变音素打字员查字典，汉字→拼音文字 → 音素序列
音素变谱印刷机排版，决定深浅音素 → 频率/响度图（梅尔谱）
谱变波形纸带过发声器，振动发声频率图 → 声波采样
语速控制印刷机快慢决定节奏伸缩每个音的时长
🔍 为什么分三步直接从文字一步跳到声音，模型要学的东西太多、又慢又糊。先查字典、再排旋律、最后发声——三步各管一段，每段都简单可靠，这就是 TTS 的通用骨架。

03关联知识点

正则化
文本正则化

数字、日期、英文缩写要"正读"——"2026"念成"二零二六"而不是逐位蹦。相当于打字员查字典前先把信里的简称改写成全称。

中间表示
梅尔谱

音素到波形的"中间图纸"——一张时间×频率的热力图，规定每个时刻各频率该有多响。有了它，语速、音调、音色都可以单独调。

参数
语速控制

--speed 伸缩每个音素的时长：调大→节奏紧凑（过快会吞字），调小→舒缓清晰（过慢会拖沓）。这是本实验重点调节的参数。

性能
RTF 实时率

RTF = 合成耗时 ÷ 音频时长。< 1 才能实时（算得比说得快），目标 0.25~0.40；> 1 说明合成跟不上播放。

04实验目标

  • 理解 TTS 的三级跳过程：文本变音素 → 音素变谱 → 谱变波形

  • 了解 RTF 实时率的含义，能用它判断合成速度是否达标

08实操步骤：合成第一句机器人语音

1输文字：用 tts_test.py 输入一句话，TTS 自动完成"查字典→排旋律→发声"三步
2合成并播放：等待合成完成，声音从阵列喇叭播出，确认清晰、不快放
3调语速对比：分别用 --speed 1.0 / 1.3 / 0.8 合成同一句话，听辨节奏差异
# —— 合成并播放（tts_test.py 核心流程）——
import numpy as np, onnxruntime as ort
text_raw = "你好，我是自然语言交互机器人"

# ① 文本变音素（查字典）：正则化 + 编码
text = run_fsts(text_raw)                     # 数字/日期正读
tokens, durs = encoder(text)                 # 音素序列 + 时长

# ② 音素变谱（排旋律）→ ③ 谱变波形（发声）
mel  = acoustic_model.run(tokens, durs)     # 频率/响度图
wav  = vocoder.run(mel)                      # 声波采样 @16kHz

# —— 播放：单声道复制成双声道（I2S 立体声出）——
pcm = (wav * 32767).astype(np.int16)
stereo = np.column_stack([pcm, pcm]).ravel() # 防 2 倍速快放
sd.play(stereo, samplerate=16000, device="plughw:4,0")

# —— 命令行 ——
python3 tts_test.py --text "你好，小飞已就位"
[TTS] syn 0.62s / audio 1.8s → RTF=0.34 ✓ → play plughw:4,0
python3 tts_test.py --text "你好，小飞已就位" --speed 1.3
⚠️ 先听感，后指标RTF 达标但声音"电音、吞字"同样是失败——听感问题优先查文本正则覆盖，其次才是模型参数。

09重点与易错点

🎯 本实验重点① 理解三级跳过程（查字典→排旋律→发声）；② 用 --speed 调语速并听辨差异；③ 用 RTF 判断合成速度是否达标。
⚠️ 常见坑现象 → 解法
2 倍速快放声音像按了快进 → 单声道音频按立体声排布播放，被两帧并一帧：np.column_stack([pcm,pcm]).ravel() 复制声道
语速过快吞字--speed > 1.5 后字间太密听不清 → 走中间值 0.8~1.3，极端值会失真
数字乱读"2026"被逐位念 → 确认 rule_fsts 文本正则文件加载正常，让数字按中文习惯读出
