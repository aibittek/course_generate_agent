EXP-06 · 第 2 章 · 综合性 · 4 学时

多模态语音情绪感知

前面的实验让机器人听清了字、也听懂了意思；这一课补上最后一件事——听出你此刻是什么心情。用文字和声音两条线索，各自判断、再合起来定案。

文字看说了什么 声音听怎么说的 两路合并判断 情感助手 · 智能客服

01问题引入：同样一句"没事"，意思可以完全相反

朋友跟你说"没事"。他要是抬着头、语气轻快，那就是真没事；可要是低着头、声音又轻又慢，你大概不会信。同一句话，情绪全藏在"怎么说"里。

1
用户："我没事。"
声音很轻、有点抖、说得断断续续。
→
2
只看文字：判定"情绪正常"
机器人接着往下推销，用户直接挂断。
→
3
再听语气：判定"很难过"
先安慰一句，再谈正事，体验完全不同。

再看三种日常说法，光看文字和加上语气，结论会差多远：

用户怎么说只看文字再加上声音
"我没事"（很轻、很慢、带哽咽）没事难过，需要安慰
"好的好的，快点吧！"（又快又响）挺配合不耐烦，快要发火了
"太棒了……"（拖长、往下掉、没起伏）开心失望，说的其实是反话
💡 本节要点情绪不只在"用了哪个词"里，还在"用了什么声音"里。只读文字，只能听懂内容；把声音的高低、大小、快慢也听进去，才听得出心情。

02原理通俗讲解：两个侦探一起断案

听朋友诉苦时，你其实同时在用两条线索：他说了哪些词，以及他是怎么说的。把这两条线索分别交给两个侦探，各自给出判断和把握程度，最后一起合计定案——这就是多模态情绪感知的全部思路。

生活里的做法对应的概念一句话解释
听他用了哪些词
"太好了" vs "随便吧"		文本通道把识别出来的文字和一张情绪词表对照，算出这句话偏"好"还是偏"坏"。
听他怎么说
声音高不高、响不响、快不快		语音通道（韵律）不用听懂内容，直接从声音里量出音高、音量、语速三个数，判断此刻有多激动。
两个侦探各自打分，再合计双模态融合按"谁更有把握"分配话语权，合出一个结论；两边打架时要降低把握，多问一句。
把结论标到一张情绪地图上情绪坐标（二维）横轴是心情好坏，纵轴是激动程度，任何情绪都能在这张图上找到位置。

语音侦探手里的三把尺子

声音这一路不需要听懂字，只量三件事：

量什么生活里的感觉能看出什么
音高（声音的高低）嗓音往上翘，还是往下沉往上翘、起伏大 → 激动、生气；压低变平 → 难过、压抑
音量（声音的大小）说话有多响一直很大声 → 生气、兴奋；突然变小 → 失落
语速（说得多快、停多久）说得急不急，中间停多久又快又不停 → 着急；又慢又常停顿 → 低落、犹豫

怎么量？一句话带过：把一段录音切成很多小段，算平均音高、平均音量，再数一数每秒说了几个字。工具里都写好了，实验时直接调用即可，不需要背公式。

这个实验在整条语音管线里的位置

1
拾音
声音里的情绪就藏在这段波形里
→
2
唤醒
开始一次对话（EXP-01）
→
3
识别出文字
文字进入文本通道（EXP-02）
→

理解意思 + 判断情绪
两个结论一起交给大模型（EXP-05）
→

合成回复
语气、语速跟着情绪走（EXP-03）
🎯 核心直觉文本通道擅长说"这是哪一种情绪"，语音通道擅长说"这份情绪有多强烈"。融合就是：用文字定性质，用声音定强度。

03关联知识点

📝
文本情绪

从"说了哪些词"看情绪。入门用一张情绪词表给词打分（"太好了"+2、"烦死"-2），再落成积极 / 消极 / 中性 / 开心 / 愤怒 / 悲伤六个标签。

🎵
韵律三特征

音高、音量、语速。不用听懂内容就能量出来，但对麦克风远近和录音音量很敏感——所以所有样本要在同一条件下录。

🔗
双模态融合

两个通道各出一个分数，按权重合成一个结论。谁更有把握就多听谁；两边结论相反时，降低把握度并追问一句。

📐
情绪坐标

横轴心情好坏（消极 → 积极），纵轴激动程度（平静 → 激动）：开心在右上、生气在左上、难过在左下、平静在右下。

04实验目标

  • 会用一张情绪词表，给识别出来的文字贴上一个情绪标签
  • 会从一段录音里量出音高、音量、语速，并说出这三项偏向哪种情绪
  • 会调融合权重，让文字和声音合成一个结论，并能解释结论为什么翻转
  • 能把情绪结论变成一句得体的"回应语气建议"，写进对话上下文

05实验环境与准备

类别配置
硬件具身智能实验箱 B2（RK3576）+ 讯飞六麦阵列
复用模块EXP-01~02 的录音与识别、EXP-05 的对话服务、EXP-03 的语音合成
文本通道一张情绪词表，纯 Python 即可，不需要模型
语音通道16kHz 单声道录音，每句 2~4 秒
素材samples/ 目录：自己录平静 / 生气 / 难过 / 开心各 3 条

python3 asr_test.py --mic-array       # 能出文字，文本通道才有原料
python3 llm_test.py --prompt "你好"   # 对话服务在线，情绪结论才有人接

# 1) 先录一条基准样本（正常语气），后面所有音量都跟它比
arecord -D plughw:4,0 -r 16000 -f S16_LE -c 1 -d 3 samples/baseline.wav

06动画讲解：文字与声音的两条线

看同一句话的两条命运线：上面一条读文字，下面一条量声音，两路判断一起进入中间的融合器，最后落到右边的情绪地图上。紫点是最终结论，4 秒一个循环：

动画 6-1：同一句"我没事"——文字这边看是"中性偏积极"，声音这边听是"低落"，两边合起来后，紫点从右上滑向左下，结论变成"难过"（4 秒循环）。字面可以逞强，声音却很难撒谎。

07互动讲解：调一调权重，看结论怎么翻

下面的 w 是"文字通道的话语权"：w=1 完全听字面，w=0 完全听语气。选一个样例、换一档权重，看结论怎么变：

情绪融合权重台 · Fusion Mixer
$ 就绪：选择样例与文本通道权重 w（0=全听语气，1=全看字面）…
🔍 观察点同一句"我没事"：w=0.5 时系统综合出"中性"，把文字的"没事"和声音的"低落"中和掉了；把 w 降到 0.2（更信语气），结论直接翻成"悲伤"。真实系统里 w 不是固定值——文字里有明确情绪词就多信文字，只有"哦""嗯"这类空话时就多信语气。

步骤 1：文字情绪——换几种说法看看

本实验提供一个课堂骨架脚本 emotion_demo.py，三个子命令分别对应文字、声音、融合。

python3 emotion_demo.py text --text "太棒了，谢谢你"
python3 emotion_demo.py text --text "随便吧，都行"
python3 emotion_demo.py text --text "烦死了，别再打了"

预期输出：每句话打印一个标签和一个把握度，例如"太棒了"→ 开心（把握 0.8）、"随便吧"→ 消极（把握 0.6）、"烦死了"→ 愤怒（把握 0.9）。换三到四句不同情绪的话，观察哪种话容易判错。

步骤 2：语音情绪——量出音高、音量、语速

# 录一条难过样本（离麦 30cm，正常音量说完整一句）
arecord -D plughw:4,0 -r 16000 -f S16_LE -c 1 -d 3 samples/sad_01.wav
python3 emotion_demo.py voice --wav samples/sad_01.wav --base samples/baseline.wav

预期输出：打印三项数值与一句判断，例如 音高 165Hz（比平时低）、音量 0.08（偏小）、语速 3.2 字/秒（偏慢）→ 难过。换成自己录的生气样本，三项应当同时反向：更高、更响、更快。

步骤 3：融合——调权重，找翻转点

python3 emotion_demo.py fuse --text "我没事" --wav samples/sad_01.wav --w 0.8
python3 emotion_demo.py fuse --text "我没事" --wav samples/sad_01.wav --w 0.5
python3 emotion_demo.py fuse --text "我没事" --wav samples/sad_01.wav --w 0.2

预期输出：w=0.8 时更信文字，判"中性"；w=0.5 时两路各占一半，仍判"中性"但分数已经被拉低；w=0.2 时更信声音，结论翻转为"悲伤"。记下结论从哪一档开始翻转，这就是这台机器人的"信任分界线"。

步骤 4：把结论变成一句回应语气

情绪标签的最终用途，是让回复的语气跟着变——写进对话上下文即可：

# 放在人设之后、用户问题之前，作为一句叮嘱
system = "你是客服助手。用户当前情绪：难过（把握中等）。
          请先安抚一句，再处理问题；语气放慢放软，不要推销。"
# 再让语音合成把语气也放慢
python3 tts_test.py --text "别急，我马上帮您处理。" --speed 0.9

预期输出：同一句用户问题，加上这段叮嘱前后各跑一次，能明显听出/看出语气差别：加之前是标准客服腔，加之后先安抚再办事。

⏱ 完成标准四类样本各自能被判对；"我没事"这类逞强句在调整权重后结论能翻转；最后能一句话说清"系统为什么这样回应"。

09重点与易错点

情绪识别最麻烦的地方是：它很少报错，只会悄悄判错。下面三个坑几乎每组都会踩：

现象原因怎么改
音量特征忽大忽小，生气和难过分不开麦克风太远、太近，或每次录音音量不一样固定 30cm 左右、一次实验只用一个录音音量；音量只看"相对平时"的变化，不看绝对值
"太棒了……"被判成开心文字只认字面，读不出反讽文字和声音结论相反时别硬判：降低把握度、按语气给结论，或直接追问"听起来不太顺利？"
两个通道调了半天，跟只用一个没区别权重一边倒（w=1 或 w=0）保留两路并让 w 有变化：文字里没有情绪词就把 w 调小，有明确情绪词再调大
⚠️ 一句话提醒结论永远带上"有多大把握"。把握低时问一句"听起来您有点着急，是吗？"，比硬猜一个标签要安全得多。

10总结与思考

🏁
完成成果

一小套四类情绪录音；文字通道与声音通道各能独立判情；可调权重的融合结论；一句写进对话的回应语气建议。

🧠
原理收获

文字定性质、声音定强度，两者互补；情绪可以放在"心情好坏 × 激动程度"这张二维地图上；两路冲突时降把握、多追问。

💭 思考题

1. 家里人打电话说"我没事，你忙你的"。你会从哪几处听出他其实不太好？如果让机器人学你，它该采集什么、又该跟什么做比较？

2. 如果机器人把"累了不想说话"的平淡语气误判成"生气"，会带来什么后果？你会怎样设计，让它宁可多问一句，也不乱下结论？
