EXP-02 · 第 1 章 · 设计性 · 4 学时

声学模型 ASR 语音识别：把声音变成文字

唤醒之后，机器人必须听清你在说什么。本实验用 sherpa-onnx 流式识别把声音变成文字：边说边出字、热词帮它听准指令词、判停决定何时收句，最后用 WER 字错率验收。

难度 ⭐⭐ · 4 学时 sherpa-onnx流式识别 热词 · 判停WER

01问题引入：从"声音"到"文字"隔着多远

EXP-01 让机器人"听见有人叫它"，但喊完"小飞小飞，前进"之后——后半句去哪了？唤醒事件只带一个词，真正的话还在空气里飘。把话变成文字，机器人要过三道关：

1边说边出字：声音是河、文字是桥——不能等说完才处理，得说话中途就"边流边译"
2一词多听："shi/zi/si"不分、环境嘈杂，同音字让裸识别错误率居高不下
3何时算完：你停顿 2 秒是在想词，还是说完了？判停错了，句子被拦腰截断
💡 解法总览课程选用 sherpa-onnx 流式识别 + Zipformer 声学模型，配合三个"旋钮"解决三难：流式分块解决边说边出字、热词解决一词多听、判停规则解决何时算完。

02原理通俗讲解：听写员的三道工序

生活比喻：会议速记员。你说话时，速记员不是等整段讲完才动笔，而是边听边写、时不时回头修正。一条 ASR 管线就是三位接力的工人：

1特征提取 = 磨面：原始波形每 100ms 切一块，转成声学特征——就像把麦子磨成面粉，扔掉音色、只留下"能识别内容"的信息
2声学模型 = 听写员：盯着特征序列，输出"此刻最可能在发哪些音"的概率，像速记员一边听一边在脑子里拼拼音
3解码 + 判停 = 终审编辑：把拼音概率拼成字，边走边吐；再看你停顿多久，判断"说完了"就画句号、固化整句
模块生活类比本实验对应
流式分块边吃火锅边涮，不等一桌菜全熟每 100ms 一段喂入，首字延迟低
声学模型听写员的"耳朵 + 拼音功底"Zipformer 输出音素级概率
热词 hotwords生僻人名预先写在稿纸上hotwords="左转 打开灯"，给编辑"划重点"
判停 endpoint看停笔多久才画句号静音 / 句号 / 最长上限三条规则
WER 字错率校对统计错字率(替换+删除+插入)/总字数，越低越好
🔍 三个核心概念① 流式识别：不等整句说完，边说边出 partial 字；② 热词：把常用指令词告诉模型，让它优先听准这些词；③ 判停：什么时候认定"这句说完了"，输出 final 整句。

03关联知识点

流式
流式识别

声音切成小块连续送入，识别结果 partial 实时更新，不用等整句说完。

热词
热词 hotwords

给模型一份"重点词表"，让它优先听准领域指令词，如"左转 / 打开灯"。

判停
判停规则 endpoint

静音超时、句末标点、最长时长三条规则，决定何时输出 final 整句。

评测
WER 字错率

用标准测试句算字错率，量化热词 / 判停调参前后的收益，是唯一的裁判。

04实验目标

  • 对着麦克风说一句话，看到 partial 边说边出字，说完后 endpoint 输出 final 整句
  • 用 热词让"左转"不再被听成"转收"，对比热词前后的识别效果
  • 体验判停：停顿太长句子被截断、停顿太短又不落句，理解参数权衡
  • 用 WER对比热词前后字错率，用数据说话验证调参收益

08实操步骤：装模型 → 跑识别 → 试热词

1装模型 + 跑识别：模型文件放入 models/zipformer-transducer/，装好 sherpa-onnx，启动实时识别脚本
2说一句话看 partial：对着阵列说一句"打开实验室的灯"，观察 partial 边说边出字，说完后判停输出 final
3加热词对比：把"左转 / 打开灯"等写入热词表，重跑同一句话，对比识别结果和 WER

python3 asr_test.py --mic-array

# —— 步骤 3：加热词，对比效果（python 配置片段）——
# hotwords.txt 写入：左转 打开灯 关闭灯 停下 前进 后退

python3 asr_test.py --mic-array

⚠️ 热词不是万灵药热词提升"领域词召回"，但修复不了增益过小、爆音这类采集端问题 —— 先看波形再调参。热词按 token 空格分词，词表只放业务相关指令词即可。

09重点与易错点

🎯 本实验三重点① 流式管线三拍：分块 → 识别 → 判停；② 热词只在 modified_beam_search 下生效；③ WER 是唯一的裁判，调参都要用数据说话。
⚠️ 常见坑现象 → 解法
热词不起作用热词设了照样错 → 检查 decoding_method 是不是 greedy（贪心直接忽略热词词汇）
句子被截断话没说完就出 final → 判停尾静音阈值调大，或说话中途停顿超过判停规则
半天不出句说完没反应 → 把判停静音阈值调小，观察灵敏度 / 准确度的权衡
  • 实时识别出字速度跟得上语速，partial 持续更新、判停后输出 final
  • 热词组 vs 非热词组的 WER 对比已记录，能解释数字变化的原因
  • "句子被截断 / 半天不出句"两种判停故障均已人为复现过一次
