CATEGORY 1 · 核心课程 / CORE-02

机器人 视觉应用与开发

12 个实验按由易到难排好：先学不用训练的传统视觉，再进 YOLO 家族，最后用 MediaPipe 做人体感知与小车控制。每个实验都先跑通三条命令看到效果，再回头讲清它为什么这样工作。

平台说明 · 实验箱 B2（XFLZ_EAI_B2_PRO）与机器人小车 C1（XFLZ_EAI_CAR1）共用同一套 RK3576 + 6TOPS NPU + HP60C 深度相机，12 个实验的视觉代码与配置完全一致。差异只有底盘：C1 多了麦克纳姆轮全向底盘，涉及小车运动的实验（实验11 体感控制）在 C1 上可直接驱动底盘，在 B2 上用 turtlesim 海龟替代验证。
WHY THIS ORDER

为什么把 OpenCV 放在最前面

原顺序是按"检测→分类→分割→跟踪→3D→人体"的技术版图排的，但对初学者不友好：第一个实验就要碰 int8 量化和 NPU 部署。新顺序改成按学习坡度排。

阶段实验技术栈为什么放这个位置
① 传统视觉实验1~3OpenCV：HSV 阈值 / QRCode / 轮廓拟合免训练、免模型、当天出效果。50 FPS 还能逐行解释"为什么选中这块"，建立信心和"可解释"直觉
② 检测与分类实验4~5YOLOv8 / YOLOv5 检测头 + RKNN第一次接触神经网络和 NPU。有了阶段①的"阈值思维"打底，更容易理解"置信度"和"调参取舍"
③ 语义分割实验6yolov8n-seg + 多线程推理池检测的进阶版：从"一个框"到"每个像素"。承接检测，又为跟踪做铺垫
④ 多目标跟踪实验7YOLOv8 + DeepSORT + ReID全课最难。需要检测（阶段②）作为输入，所以必须排在后面
⑤ 人体感知实验8~10MediaPipe Blaze 系列 + 深度相机换一套模型家族（Blaze 而非 YOLO）。人脸→骨骼是同一套级联思路的递进；深度相机放在骨骼之后，因为此时已熟悉坐标和像素，正好补上"距离"这一维
⑥ 视觉控制闭环实验11~12关键点 + cmd_vel / 手势分类收官。需要骨骼（实验9）的坐标才能做动作判断，所以必须最后
一句话 · 先用没有模型的实验把"看图→出数字"这件事做熟，再用有模型的实验把同一件事做得更强，最后让结果驱动动作。三段各 3~4 个实验，坡度均匀。
SETUP

开课前要配好的三件事

① 两个终端都要 source

每开一个新终端，先跑 source /opt/ros/humble/setup.bash 和 source ~/ros2_ws/install/setup.bash。漏了会报"找不到包"，这是最高频的卡点。

② 两个终端都要同一个域号

实时实验要先起相机 ros2 launch ascamera hp60c.launch.py，然后两个终端都 export ROS_DOMAIN_ID=2。域号不一致，相机在发、程序在等。

③ 用浏览器看画面

板子没有显示器也能看结果：http://<板IP>:8080/xxx.mjpg。端口分配：实验1~7 用 8080（不同时开），实验8=8081、9=8082、10=8083、11=8084。

FAQ

开课前的三个常见疑问

完全零基础，能跟上吗？

能，而且比原来容易。这三个开篇实验（颜色/二维码/轮廓）不需要任何深度学习基础，也不碰模型文件。第一个实验跑通只要五分钟。

必须按顺序学吗？

建议按顺序。实验4 的检测是实验6、7 的输入；实验9 的骨骼点是实验11 的输入；实验12 又用上了实验9、11 的全部思路。想跳着学，至少先把目标实验的前置做完。

没有板子能学完吗？

实验1~3 的原理和参数可以在 PC 上跑通。实验4 之后涉及 NPU 推理，只能在板子上验证。有硬件体验差别很大。
