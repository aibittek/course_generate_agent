LEARNING PATH

学习路径建议

先原理，后实操

每个实验的第 02 节通俗原理和第 06 节动画务必先看——知道了"这个框是怎么算出来的"，板端报错时才知道去哪儿排查。

检测是全课程地基

EXP-01~02 的 letterbox、NMS、输出张量解读贯穿后续所有深度学习实验，建议把互动台的阈值调到滚瓜烂熟。

输入契约是最大坑源

YOLO 要 uint8 直喂、人脸模型要 float32 [0,1]、骨骼模型要 127.5/128——三种契约混用就是"检测全废"的头号原因，对照互动台亲手试一次。

用 turtlesim 先验证控制

EXP-11、12 的体感控制先在 turtlesim 海龟上跑通指令链路，再上真车 —— 控制类实验的安全边界永远排第一。

HOW IT WORKS

四步学习法

每个实验的十个小节，落到行动上就是这四步——按此节奏走完 12 个实验约 48 学时：

STEP 01 · 读懂问题第 01~05 节从真实场景切入，跟着生活比喻搞懂原理，再确认实验目标、硬件与数据集是否就绪——没想明白就别急着敲命令。
STEP 02 · 看懂机制第 06~07 节先看 SVG 原理动画把算法动起来，再到互动实验台亲手调参数：改一个值、看一处变化，把"公式"变成"手感"。
STEP 03 · 板端实操第 08 节原样复现源讲义的真实命令与代码，跑单元测试对照预期输出；出错先回第 09 节坑表按"现象指纹"排查。
STEP 04 · 复盘拓展第 09~10 节对照易错点清单逐项打勾，最后合上页面回答两道思考题——答不上来，说明该重看第 02 节。

TROUBLESHOOTING

常见故障速查

全课程反复出现的几类"名场面"，先在这里认脸，实验中遇到就不会慌：

检测框全部消失

指纹：detections=0 / presence 掉到 1e-9 量级。九成是输入契约错——图片是 uint8 [0,255] 而模型要 float32 [0,1]，或 RGB/BGR 顺序送反。对照第 07 节互动台的契约开关亲手复现一次。

板端跑得动、PC 上跑不动

指纹：rknnlite ModuleNotFoundError。NPU 推理只在实验箱上可用；x86 请用 ONNX/PyTorch 后端跑单测与 demo，或先 --check 验证契约再上板。

ros2 topic list 看不到话题

指纹：相机节点在跑但话题列表为空。每个终端都要 export ROS_DOMAIN_ID=2 并 source 对应 install 空间；域不一致 = 各说各话，互相不可见。

MJPEG 地址打不开

指纹：浏览器 404/超时。确认用的是板端 IP 而非 localhost、端口与该实验一致（8080~8084 按实验递增）、demo 进程存活且处于 --ros 或预览模式。

改了 config 没生效

指纹：行为与配置文件不一致。launch 读的是安装空间里的配置——改完必须 colcon build --symlink-install 并重新 source install/setup.bash。

画面上出现问号方块

指纹：状态栏 / 标签中文乱码。cv2.putText 不支持 CJK 字体，所有窗口内文字一律用英文——这不是乱码 bug，是 OpenCV 的显示限制。
