二维码识别与解码

从"回"字角标定位到 Reed-Solomon 纠错：先学会生成一张能扫的二维码，再让小车摄像头在单码 / 多码 / 轻度遮挡 scenarios 下都能稳稳读出内容。

难度 ⭐ · 4 学时 qrcode 7.4.2 cv2.QRCodeDetector 19 项单元测试 文件 / 相机 / ROS 三入口

01问题引入：为什么扫码几乎"秒回"？

快递驿站里，面单朝下、褶皱、灯光反光，扫枪却"嘀"的一声就读出单号；食堂收款码贴在亚克力板上，被贴纸蹭掉了一角，手机照样识别。二维码看起来只是一堆黑白小方块，但它抗污损、抗反光、能一口气读多个的能力从何而来？

更让人好奇的是：机器怎么知道二维码在画面的哪个位置、歪了多少度？一张图片里同时出现 3 个二维码时，为什么不会把左上角的定位图案和右下角的数据区"缝合"成一段乱码？本实验从零生成一张二维码，再用 OpenCV 逐帧解码，把这两个问题彻底拆开。

🎯 本实验要验证的三件事① 生成参数（纠错等级、版本）如何决定二维码的"耐用度"；② 定位角标如何让检测器在任意旋转角度下找到码；③ 多码场景为什么要"逐码分图"再解码。

02原理通俗讲解：一张码的"三层结构"

先把二维码想成一张带花边的信纸。信纸的正文是数据，花边不只是装饰——三个角上的"回"字印花就是这张纸的"装订孔"：无论你把信纸旋转、折叠成什么角度，只要三个孔凑齐，读信的人立刻知道哪边朝上、纸歪了几度。

🔍 角标 Finder
7×7 的"回"字

左上、右上、左下各一个。检测器先在图里找三个同心方块，用它们的相对位置直接算出码的旋转与倾斜——这就是"任意角度秒扫"的秘密。

📏 校正 Alignment
版本 ≥2 才有

版本变大、码变"胖"后纸会"折"，校正图案负责逐区微调，防止远处的数据区被透视拉歪。

📖 数据 Data
按掩模打散的字节

正文按固定"九宫格阅读顺序"排布，并 XOR 一层掩模图案打散——避免出现大片纯黑/纯白让检测器跟丢。

💊 纠错 Reed-Solomon
L 7% / M 15% / Q 25% / H 30%

像涂改液：污损不超过额定比例，被划掉的字还能"复原"。等级越高冗余越多，同容量下码也越大。

容量公式只有两行：模块边长 M = 17 + 4 × 版本（版本 1 是 21×21，版本 40 高达 177×177）。生成时三个关键旋钮：version（容量）、error_correction（耐污度）、box_size / border（每个模块画多大、留多宽静默区）。

⚠️ 为什么"高纠错 + 中文"反而是坑？H 等级冗余最长，解出的字节序列更长、更容易在板端截断或触发编码歧义——源讲义明确要求：不要用 H 等级编码中文，选 M 并控制内容长度最稳。

03关联知识点

几何
透视与仿射

三个角标构成参照系，任意倾斜的码都能被"扶正"成正视图再采样读取。

编码
GF(256) 有限域

Reed-Solomon 纠错建立在有限域运算上，本质是"多项式除法取余"做奇偶校验。

工程
静态 vs 流式

图片文件解码是单帧验证，MJPEG 流才是真实接入形态，两者的失败模式不同。

颜色
BGR 通道序

qrcode 库输出 RGB，必须 cv2.cvtColor(..., COLOR_RGB2BGR) 才能被 OpenCV 正确写盘。

  • 前置：OpenCV 图像读写与 cvtColor（EXP-03）。
  • 后续：EXP-05 轮廓与多边形——角标本身就是一对"同心轮廓"。
  • 串课：识别出的内容可以喂给 ROS2 topic（EXP-00 系列）驱动小车行为。

06动画讲解：角标定位的三步走

三个"回"字角标依次被锁定（青色闪烁）→ 三心连线确定朝向与倾斜（橙色虚线）→ 扫描线按掩模顺序读出数据区。角标缺失任何一个，检测器就无法解算姿态，码再清晰也读不出。

看清动画里的顺序：先定位、再纠偏、后读数。这也解释了多码场景的困境——三个角标必须属于同一个码；整图一次性检测时，检测器可能把 A 码的左上角和 B 码的右上角配成一对，输出一段"缝合乱码"。

ok, pts = detector.detect(img)         # 找到 N 个码的四角点

09重点与易错点

  
⚠️ 最高频翻车点生成端做了 RGB→BGR 转换，解码端却拿"看起来发灰"的图硬扫——先确认色彩通道，再怀疑算法。其次是多码不裁剪：整图 detectAndDecode 一次返回的第一条结果在多码场景下不可信。

  

    
现象根因处理

    
板端解码中文乱码字体 / 编码链不齐 + H 等级字节流过长纠错等级改 M，内容控制在 40 字符内

    
3 张码只读出 1 张或读串QRCodeDetector 整图多码串扰逐码分图 + MAX_DETECT_PASSES=8

    
ModuleNotFoundError: qrcode生成库未安装pip install qrcode 后重跑

    
生成函数抛 ValueErrordata 为空字符串 / 全空格入口处校验内容非空

    
打印样张扫不出border 静默区被裁、box_size 太小border ≥4 模块、打印后留白边

    
H 等级 + 中文板端失败冗余字节过长，板端解不出降级到 Q/M，删掉多余字符

    
相机链路 404MJPEG 路径或端口不对核对 qrcode.mjpg 路径与模块端口

    
内容 40 字符被截断单码 ROI 采样不足 / 版本太小version 自适应或手动加 1
