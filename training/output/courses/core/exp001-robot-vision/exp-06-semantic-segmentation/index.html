图像语义分割

从"框住人"进化到"抠出人"：YOLOv8n-seg 的 13 路输出里，32 通道 proto 与 32 维掩码系数一乘，像素级前景掩码就诞生了，再用 Alpha 合成把人贴到任意背景上。

难度 ⭐⭐ · 4 学时 yolov8n-seg 13 输出 + proto 38 项单元测试 MJPEG :8080/seg.mjpg

01问题引入：为什么"框住"还不够？

直播绿幕能把你从教室里"抠"出来换成虚拟背景——这个需求靠矩形框永远做不到：框内既有你也有窗帘。语义分割回答的是逐像素问题：这个像素属于"人"还是"背景"？在机器人场景里它更关键：机械臂要绕开工人、巡检要统计仪表盘区域人流，都必须知道目标的精确外沿，而不是一个粗框。

本实验在实验箱 B2 上跑 yolov8n-seg 的 RKNN 版，实时输出 person 掩码并做背景合成。真正的难点藏在模型输出里：13 个输出张量、32 通道低分辨率 proto、掩码阈值的微妙平衡——差一档就"边缘碎成渣"或"人被啃掉一块"。

🎯 本实验的三个关卡① 看懂 13 输出的布局与掩码分支；② 掌握 mc × proto → sigmoid → 上采样 → 阈值的标准融合式；③ 调出不碎边、不缺块的前景掩码。

02原理通俗讲解：三十二张"透明胶片"

把掩码生成想象成洗照片叠底片。网络后段吐出 32 张模糊的小图（proto，160×160），每张都是一种"形状底片"；每个检测到的人则给出 32 个系数（mc，像 32 支颜料的配比）。把系数乘到对应底片上、全部加起来——一张只属于这个人的"透明胶片"就显影了：

📦 13 路输出
三尺度 × 4 段

3 层特征图 × [box 64 维 + cls 80 维 + cls_sum 1 维 + mc 32 维]，外加 proto [1,32,160,160]。cls_sum 先做粗过滤，省下大量无效计算。

🎨 mc × proto
32 次乘加

mask = Σ mc[i] × proto[i]——这一步就是"按配比混合 32 张底片"，结果是低分辨率的单人热力图。

☀️ sigmoid 显影
logit → 0~1

乘加结果还是无量纲的 logit，过一次 sigmoid 把它压成"属于人的概率"，画面上看着像慢慢显影。

🔍 阈值裁剪
mask_thr

概率 > 阈值 → 1（前景），否则 0。阈值太低边缘发毛带毛刺，太高人体被"啃"——它是本课最重要的手感参数。

📐 放大回原帧
INTER_LINEAR

160×160 的胶片要插值回 640×640 并摘掉 letterbox 的 pad，才能和原图逐像素对齐——用 NEAREST 会锯齿成马赛克。

🎞 合成发布
Alpha 公式

I_out = I_orig × M + I_bg × (1−M)：M=1 处留人，M=0 处换景。多人掩码取并集即可一次合成。

⚠️ 掩码的两个"错位"陷阱① RGB/BGR：proto 分支按 RGB 流水线训练，混用通道会让合成半边脸发青；② pad 不摘：letterbox 补的灰边不除掉，掩码整体会相对原图下移/缩小。这两个错都不报错，只让你"看着差点意思"。

06动画讲解：13 路输出合成前景掩码

掩码生成流水线：32 个系数（左，青色柱）加权求和 32 张 proto 底片（中，卡片堆）→ sigmoid 显影成概率 → 红色 mask_thr 阈值线来回扫描，线压得越低绿色人形越"胖"、越高越"瘦" → 最终输出二值人形掩码。整条链只发生在低分辨率端，最后一步才放大回原帧。

手写掩码后处理核心（本课最重要的 12 行）：

# 1) 选中检测框对应的 mc 系数
mc = masks_sel[det_idx]                  # (N, 32)
# 2) 系数 x proto 并按帧累加 —— 连续张量要 read + numpy
prod = np.matmul(mc.astype(np.float32),
                 proto.reshape(32, -1))  # (N, 160*160)
# 3) sigmoid 显影
prob = 1.0 / (1.0 + np.exp(-prod))
# 4) 单人掩码上采样到输入尺寸（双线性；NEAREST 会锯齿）
m = prob[i].reshape(160, 160).astype(np.float32)
m = cv2.resize(m, (640, 640), interpolation=cv2.INTER_LINEAR)
# 5) 摘 letterbox pad、再缩放回原帧、阈值化
m = m[pad_top:640-pad_b, pad_left:640-pad_r]
m = cv2.resize(m, (W, H), interpolation=cv2.INTER_LINEAR)
bin_mask = (m > mask_thr).astype(np.uint8)   # 默认 0.5


    
4
前景合并 + 三种背景合成：

# 多个 person 掩码取并集
foreground = np.zeros((H, W), np.uint8)
for mk in person_masks: foreground = np.maximum(foreground, mk)

# background: black / solid / image —— 核心是同一个 Alpha 公式
M = foreground[..., None].astype(np.float32)      # (H,W,1)
I_out = (img * M + bg_img * (1 - M)).astype(np.uint8)

09重点与易错点

  
⚠️ 第一大坑：低分辨率端一切正常，原帧上一看全是错掩码链的错误几乎都不抛异常：pad 没摘→整体位移；RGB/BGR 混→颜色诡异；INTER_NEAREST→边缘锯齿。对照原图逐像素检查四项：通道序、pad、resize 顺序、阈值。

  

    
现象根因处理

    
掩码边缘碎渣、人身上有洞mask_thr 偏高 / 低分辨率噪声调到 0.4~0.5，必要时形态学闭运算

    
掩码粘到背景、人"变胖"mask_thr 偏低提到 0.55~0.6 对照测试

    
掩码整体相对人下移letterbox pad 未摘除按 pad_top/left 切片后再放大

    
合成脸发青/发红RGB 与 BGR 通道混用全链路统一 BGR → 转一次并固定

    
掩码放大后马赛克用了 INTER_NEAREST全链路 INTER_LINEAR

    
浓度无效：第二个人没掩码并集写成了"覆盖"或 NMS 后索引对错np.maximum 并集；核对 det_idx 映射

    
NMS 后框数骤减/不变忘了 max_wh=7680 全类一次处理按官方写法一次性 NMS

    
帧率掉到个位数workers=1 或同实例并发推理恢复 workers=3，每 worker 独立 RKNN 实例

    
MJPEG 404端口/路径错核对 :8080/seg.mjpg
