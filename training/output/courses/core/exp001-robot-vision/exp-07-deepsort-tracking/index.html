DeepSORT 多目标跟踪

检测只管"这一帧有谁"，跟踪才回答"上一帧那个是不是还是他"。卡尔曼预测 + 马氏门限 + ReID 外观 + 匈牙利匹配，四件套合体让 ID 在遮挡与交错后依然不丢。

难度 ⭐⭐⭐ · 4 学时 YOLOv8 + deepsort.rknn Kalman + 匈牙利 38 项单元测试 MJPEG :8080/track.mjpg

01问题引入：为什么"每帧检测"不等于"跟踪"？

停车场入口的相机每帧都能框出 8 辆车，但管理端要问的是：昨晚 23:01 那辆白色轿车今天又来了吗？如果只做逐帧检测，两辆车交错一分开，编号就可能互换；一辆车被大卡车挡住 2 秒再出现，系统会认为"旧车消失、新车出现"，计数翻倍。

跟踪的本质是跨帧的身份维护。难点有三：① 车在动，得先"猜"它这帧大概在哪（预测）；② 猜的和检测的对不上怎么办（关联门限）；③ 两辆车长得一样怎么区分（外观 ReID）。本实验在实验箱 B2 上把 DeepSORT 全链路跑起来，双模型（检测 + ReID）双 RKNN 并行，12~15 FPS 实时输出稳定 ID。

🎯 综合性实验的"综合"在哪这是全课程信息密度最高的一课：数学（卡尔曼/马氏距离/匈牙利）、深度学习（YOLO 检测 + ReID 嵌入）、工程（双池并行 + 双缓冲 + 配置热管理）三条线交汇，38 项单测逐一守护。

02原理通俗讲解：一场"点名 + 认脸"的接力

把跟踪想象成老师在操场上认学生。学生在跑（运动），偶尔躲到树后（遮挡），还可能两人穿同款校服（外观相似）。DeepSORT 的流程就是一位有经验老师的点名法：

🏃 卡尔曼预测
"他应该跑到这了"

每个轨迹维护 8 维状态 (cx, cy, a, h 及其速度)。新一帧到来前，先外推位置——像老师提前把目光落在孩子跑动方向的前方。

📏 马氏距离门限
"别点太远的人名"

预测有不确定性（协方差），马氏距离按"不确定度"归一化量差距。卡方 95% 门限 CHI2INV95=9.4877：超出门限的检测不许和该轨迹配对，防止张冠李戴。

🎓 级联匹配
先点最近最活跃的

按轨迹"新鲜度"从新到旧依次抢匹配——刚出现的轨迹最需要确认，老而稳定的可稍后处理。这就是 n_init=3 的来历：连续 3 帧匹配上才"转正确认"。

🧒 ReID 外观特征
看脸不只看名字

把候选框抠成 64×128，过 deepsort.rknn 得到 512 维向量，ImageNet 归一化后与轨迹的外观库算余弦相似度（max_dist=0.2）。遮挡后重逢，靠"长相"把 ID 接回来。

🔤 匈牙利算法
全局最优点名

相似度矩阵交给匈牙利（scipy linear_sum_assignment）一次性求"总代价最小"的指派，避免贪心造成的连锁错配。

♻️ 生命周期
确认与注销

n_init=3 转正；连续 max_age=70 帧没匹配上才注销——给长遮挡留足复活窗口。纯 IoU 匹配（IoU 门 0.45/0.8）作为 ReID 缺失时的回退。

⚠️ 三种典型失败对应三个环节ID 频频变 → 匹配代价没调好（max_dist/iou_thr）；遮挡后再现 ID 变了 → max_age 太短或 ReID 特征库没留住；两车交错互换 ID → ReID 区分度不足或门限过松。先定位环节，再动参数。

数学

卡尔曼是"最优加权平均"：预测越飘，越信检测；检测越噪，越信预测。

下游
行为分析

稳定 ID + 帧时序 = 目标轨迹，可做车流统计、徘徊检测、区域入侵（衔接 ROS2 topic 输出）。

  • 配置文件：config/track_config.yaml——含 score_thr、iou_thr、classes=[2]、mode=deepsort/sort、ReID 与生命周期全部旋钮。
  • 工程位置：ros2_ws/src/xflz_eai_car1/vision/07_multi_object_tracking/。
  • 回退语义：ReID 模型缺失时自动降级 sort 模式并打印告警——这是设计行为，不是崩溃。

06动画讲解：交错车辆的 ID 保卫战

两辆车（蓝 ID7 / 橙 ID12）沿交叉路线行驶：紫色椭圆是卡尔曼预测的马氏门限（随不确定性张缩），中段遮挡带里检测短暂中断——轨迹靠预测维持并在 max_age=70 帧内等它回来；ReID 外观特征保证两车重见时不互换 ID。ID 标签全程不变，这就是"跟踪"与"逐帧检测"的本质差别。

09重点与易错点

  
⚠️ 排错从"ID 症状"入手ID 频切 → 先看 mode 是不是悄悄回退成了 sort、max_dist 是否过松；轨迹拖尾不消失 → max_age 过大；新目标确认慢 → n_init 与 min_confidence 联动。禁止一次改三个参数——单变量隔离是跟踪调参第一纪律。

  

    
现象根因处理

    
ID 频频更换ReID 回退 sort / max_dist 过松过紧看告警；max_dist 0.2 起步微调

    
遮挡后再现是新 IDmax_age 太短或外观库没留住max_age ≤70；核查 nn_budget

    
两车交错互换 ID外观太像 + 门限过松调低混淆源（角度/分辨率），收紧 max_dist

    
轨迹残留"幽灵车"max_age70 过长或阈值过低降 score_thr 反查误检，缩 max_age

    
启动打印 fallback sort 告警deepsort.rknn 缺失/路径错恢复模型文件，属设计内降级

    
帧率远低于 12 FPS池未并行 / 单实例串行pool.workers=3、ReID 池 2、双缓冲

    
--ros 无帧未拉相机或 domain 冲突hp60c.launch.py + ROS_DOMAIN_ID=2

    
推理随机崩溃多个进程共享同一 RKNN 实例每 worker 必须独立加载自己的 RKNN
