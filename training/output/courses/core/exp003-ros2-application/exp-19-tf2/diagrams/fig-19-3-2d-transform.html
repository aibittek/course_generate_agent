二维 TF 变换：子坐标系 base_link → 父坐标系 map

xmap = xbl cosθ − ybl sinθ + tx
ymap = xbl sinθ + ybl cosθ + ty
左图实时计算结果：
一句话理解：点 P 没有动，只是从一把尺子（子 base_link）上的读数，换算到另一把尺子（父 map）上。
  • ✅变换顺序：先旋转，后平移（ROS TF 固定顺序）
    ⚠️ 顺序不能颠倒！必须先把 P 的方向转正对齐 K，再叠加原点偏移。
  • ✅参数含义
    tx, ty子坐标系 base_link 的原点 O′，在父坐标系 map 中的位置 θbase_link 相对于 map 逆时针旋转的角度 xbl, ybl点 P 在子坐标系 base_link 里的读数 xmap, ymap同一个点 P，换算到父坐标系 map 里的读数
