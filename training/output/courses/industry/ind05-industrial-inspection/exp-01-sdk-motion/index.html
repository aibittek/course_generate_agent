SDK 运动控制与巡检准备

融合理论「四足运动与巡检概述」：先认识 Go2 Edu 硬件与三类巡检任务，再安装 Unitree SDK 与 ROS2 驱动，用速度指令遥控前进转向、站起趴下、读回状态——验收标准：指令驱动四足运动正常。

实践/理论unitree_sdk2pyunitree_ros2低速起步

01学习目标

  • 说出 Go2 Edu 关键硬件：3D 激光雷达、深度相机、高清相机、足端力传感、Jetson Orin 40 TOPS 机载算力。
  • 讲清三类巡检任务：表计读数、异常检测、自主巡逻回充，以及四足运动在其中承担的角色。
  • 完成 Unitree SDK（Python）与 ROS2 Go2 驱动安装，跑通状态读取与运动示例。
  • 用指令遥控四足前进、转向、站起、趴下，达到「指令驱动四足运动正常」的验收线。
  • 牢记安全铁律：低速起步，避免跌落与碰撞，异常时先发停止/趴下指令。
素材说明：本课无本地视频素材——固定章节的动态演示自制动图 GIF（来自开源仓库 README）与 SVG 原理动画替代，不虚构实拍录像。

02原理：四足运动与巡检概述（理论 1 融合）

把机器狗想像成一位厂区巡检员：四条腿是它的「交通工具」，身上的雷达和相机是「眼睛」，脑子是机载的 Jetson Orin。它要干的活就三样——抄表（对着表计拍一张，后面用 YOLO 认数字）、看异常（跑冒滴漏、烟火、异物）、自己巡逻自己充电（定时出门，见桩就回）。这三样任务的共同前提：狗得先听指挥、走得起、停得稳——这就是本实验要打通的运动控制层。

四足运动能力：一个运动服务管所有动作

Go2 的运动不靠你直接拧电机——机上跑着一个运动服务（sport mode），你发「请求」，它负责步态平衡。订阅 /sportmodestate 话题能看到它的状态字典，其中两个字段最常读：mode（0=默认站立、1=平衡站立、3= locomotion 运动中、5=趴下、8=恢复站立……）与 gait_type（0=待机、1=trot 对角小跑、2=run、3=爬楼），外加 body_height、velocity、foot_force 等。控制侧走 /api/sport/request 话题发 unitree_api/msg/Request 请求——SDK 里的站立/趴下、速度移动、姿态控制，底层都是它。

站立 / 趴下
SDK 的 StandUpDown()：起身与卧倒，是每轮实验的第一与最后一个动作。
速度指令
VelocityMove()：vx/vy/yaw 三元组遥控——前进、平移、原地转向都从这里来。
姿态指令
BalanceAttitude()：调整机身 roll/pitch/yaw，过坎抬身用得上。
状态回读
read_highstate / /sportmodestead：发完指令必须回读，确认狗真的动了。
生活化类比：运动服务像「驾校教练」：你（SDK 脚本）只说「起步、左转」，离合油门刹车它替你协调；但你若同时用 App 手动模式抢方向盘，两套指令就会打架——所以底层操作前要先关掉 sport_mode，一次只听一个人的。

  1. 配网：网线连接 Go2，网卡 IPv4 设静态（示例 192.168.123.99/24），ifconfig 记下接口名。
  2. 装 Python SDK：依赖 Python≥3.8、cyclonedds==0.10.2、numpy、opencv-python；源码方式 pip3 install -e .（找不到 cyclonedds 时先本地编译并导出 CYCLONEDDS_HOME）。
  3. 装 ROS2 驱动：克隆 unitree_ros2 → 安装 rmw_cyclonedds 依赖 → 编译 cyclonedds_ws 与 unitree_go/unitree_api 包 → 用 setup.sh 配置接口名与 RMW_IMPLEMENTATION。
  4. 验证链路：ros2 topic echo /sportmodestate 有数据滚动即通；无真机时用 setup_local.sh（回环口 lo）跑本地流程。
  5. 运动序列：先 StandUpDown 站起 → VelocityMove 用最低速度档走直线与小半径转向 → 收到停止 → 趴下 → 回读状态确认 mode/gait 正常。
  6. 留痕：录下「指令-动作」对照视频或截图状态话题，作为「指令驱动四足运动正常」的验收证据。

05关键命令

以下命令均摘自 unitree_sdk2py 与 unitree_ros2 官方 README，网卡名按实机替换。

# ① 安装 Python SDK（依赖 cyclonedds==0.10.2 / numpy / opencv-python）
git clone https://github.com/unitreerobotics/unitree_sdk2py.git
cd unitree_sdk2py && pip3 install -e .

# ② 读高层状态（enp2s0 换成连接机器狗的网卡名）
python3 ./example/high_level/read_highstate.py enp2s0

# ③ 运动测试：站立/趴下、速度控制、姿态控制（择一放开注释）
python3 ./example/high_level/sportmode_test.py enp2s0
#   test.StandUpDown()      站立与趴下
#   test.VelocityMove()     速度控制（低速起步！）
#   test.BalanceAttitude()  姿态控制

# ④ ROS2 侧：source 环境后验证状态与状态机
source ~/unitree_ros2/setup.sh
ros2 topic echo /sportmodestate        # 运动状态：mode/gait/velocity
ros2 topic echo /lowstate              # 底层状态：关节、IMU、电池
ros2 topic echo /wirelesscontroller    # 遥控器摇杆 lx/ly/rx/ry 与 keys

# ⑤ 站立示例（example 工作空间编译后）
cd ~/unitree_ros2/example && colcon build
./install/unitree_ros2_example/bin/go2_stand_example
安全闸门：VelocityMove 示例速度按官方写法跑即可，课堂自行改参数时把线速度压到最低档、先空旷后狭窄；狗出现抬腿异常/连跌趋势，立即让它趴下（lieDown 模式）再排查。任何时刻遥控器在手。
控制走哪条路
高层：SDK/Ros2SportClient 组 Request → 发到 /api/sport/request，运动服务统一执行。
状态走哪条路
运动服务广播 /sportmodestate 与 /lowstate，订阅即可，不用轮询。
为什么用 DDS
ROS2 与 Go2 底层同为 CycloneDDS，话题可以直连，不必二次封装。
验收判据
同一脚本三连：站起→低速直线+转向→趴下，状态话题全程无丢帧即为通过。

06动画：步态相位与指令链路

动画 1-1：上半部为俯视 trot 步态——绿脚踩地、灰脚摆动，两条对角支撑线交替亮起；下半部显示重心投影在支撑多边形内小幅晃动却不出界，这就是四足不摔倒的全部秘密。
动画 1-2：黄点=下行指令流（脚本 → /api/sport/request → 运动服务执行），蓝点=上行状态流（/sportmodestate 回读验证）——控制与反馈构成完整闭环，只发不收等于蒙眼开车。
观察步态动画里为什么摆动腿总比支撑腿「快进快出」？摆动期间支撑域只剩一条对角线，机身重心越稳、留给纠错的时间越短——所以速度越快、地面越滑，这条线越不能抖，这正是「低速起步」的物理原因。

07互动：步态相位步进器

手动步进 trot 步态四相位，观察支撑足与重心安全判据

把相位走完一圈你会发现：trot 每个瞬间只有对角两足着地，支撑域是一条线段，重心投影必须压在这条线上才稳——这就是四足机器人「走路要算数学」的直观版本。

08常见问题

Q pip 报 Could not locate cyclonedds？
cyclonedds==0.10.2 没装好：按 README 本地编译 cyclonedds，再 export CYCLONEDDS_HOME 指到 install 目录重装。
Q ros2 topic list 是空的？
三查：网段是否 192.168.123.x、setup.sh 里网卡名是否写对、RMW_IMPLEMENTATION 是否 rmw_cyclonedds_cpp 且已 source。
Q 狗不听速度指令？
先看 /sportmodestate 的 mode：处于手动/阻尼等非 locomotion 态会拒答；确认运动服务在线、无 App 抢占。
Q 指令一发就猛窜？
示例里残留了较大的目标速度：把 VelocityMove 参数压回最低档再跑，牢记低速起步、预留急停空间。
Q 没有真机怎么练？
source setup_local.sh 用回环接口跑 ROS2 流程，状态话题用录包回放；运动真操环节统一上真机。
Q 要用 App 额外操作吗？
高层 SDK 模式用默认运动服务即可；只有跑底层 low_level 控制前才需在 App 关闭 sport_mode，避免指令打架。
Q 前置相机怎么取帧？
unitree_sdk2py 提供 example/front_camera/camera_opencv.py（需图形界面，ESC 退出），EXP-04 拍照复用它。
Q 遥控器数据能读吗？
能：订阅 /wirelesscontroller 得 lx/ly/rx/ry 摇杆量与 keys 键值，可做手动接管的二次判据。

09拓展阅读

  • unitree_rl_gym（BSD-3）： Isaac Gym 里 train.py --task=go2_* 训练步态策略——机器狗的「天生会走」其实是学出来的，与运动服务的「写死规则」对照着看。
  • unitree_ros / robots/go2_description：官方 URDF 模型可进 RViz 看结构，但 Gazebo 仿真只支持底层关节、不支持完整行走——这是要讲清的局限，别指望仿真里遛狗。
  • 宇树机载 unitree_slam / mid360_driver：官方闭源服务，课堂可演示其 App 建图效果，但不随课分发——与本课 slime/开源方案（EXP-02）形成对比。
  • go2_ros2_sdk：一个 launch 集成 pointcloud_to_laserscan、slam_toolbox、Nav2、joy 遥控与 Foxglove，EXP-02/03 的主力底座。
  • Unitree 官方开发者文档 sports_services / Basic_services：Request api_id 全表，做自定义指令（灯光、音量、避障开关）时回来查。
