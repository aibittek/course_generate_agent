机械臂硬件组装与串口识别

本课是全课的视频重点课：9 段指导视频覆盖主臂安装、从臂安装、设置电机编号、Gripper 与 Joint1~Joint5 逐关节上臂全过程。你将把主臂卡钳夹紧桌面、从臂卡上小推车，接对 5V/12V 两路电源与串口线，再用 lerobot-find-port 找到每条臂的端口并落成永久别名——这是"从零件到能被软件认出来的机械臂"最关键的一步。

难度 ⭐⭐ · 8 学时 9 段装配视频5V 2A / 12V 8A lerobot-find-port四臂别名

01学习目标

  • 能区分主臂与从臂的安装方式与供电规格：主臂 5V 2A 固定桌面、从臂 12V 8A 卡小推车
  • 能按 9 段视频独立完成 设置电机编号 → Joint1~5 / Gripper 逐关节装配
  • 能说出六关节的英文名与中文含义：shoulder_pan / shoulder_lift / elbow_flex / wrist_flex / wrist_roll / gripper
  • 能执行"先接电源、后插 USB"的正确插拔顺序与 lerobot-find-port 找口流程
  • 能用 udevadm info 核对 ID_SERIAL_SHORT 并确认四条别名已生效

02原理讲解：串口是"对讲机"，供电是"两路电"

把机械臂想成住在楼里的住户，串口（USB 串口，/dev/ttyACM*）就是住户与物业之间的对讲线：主机发角度指令、臂回传位置反馈，全走这一根线。两个要点：

1供电分两路：主臂是示范端，吃电少（5V 2A）；从臂要真正举东西，吃电大（12V 8A）——插错电源轻则不工作，重则烧板
2先电后 USB：先给臂通电、再插 USB 到电脑，顺序颠倒可能导致枚举失败（第 03 章明确警告"顺序不要颠倒"）
3端口会变、序列号不变：重启后 ttyACM0/2/3 顺序可能重排，但每块板的序列号（如 5B79018622）是出厂烧死的——所以找口后要写 udev 别名

再看"六关节"：SO100 系列每条臂有 6 个受控自由度——底座水平旋转（shoulder_pan）、肩俯仰（shoulder_lift）、肘俯仰（elbow_flex）、腕俯仰（wrist_flex）、腕滚转（wrist_roll）、夹爪开合（gripper）。设电机编号就是告诉每个关节里的电机"你是几号"，编号错一个，未来遥操作时手臂就会"往东施力往西动"。

03硬件与材料

部件数量/规格安装要点
主臂（leader）×2 · 电源 5V 2A卡钳旋转夹紧固定桌面；接线左电源、右串口
从臂（follower）连底座×2 · 电源 12V 8A连同底座一起卡到小推车上；同样左电源、右串口
机械臂摄像头装于臂上注意防呆口方向，插反插不进
从臂摄像头装于从臂顶部按防呆口卡入
摄像头线×3 接主机插电脑背面，且必须按指导顺序插入
串口线经拓展坞接机箱前面的拓展坞，插口和顺序无要求

口诀：摄像头线要"按顺序插背面"，串口线可"随便插拓展坞"——两者约束完全不同，别混。

04步骤实践：跟着 9 段视频完成装配

1主臂上桌：卡钳旋转夹紧，按"左电源右串口"接线（看主臂安装.mp4）
2从臂上车：连底座卡到小推车，接 12V 8A 电源（看从臂安装.mp4）
3设置电机编号（设置电机编号.mp4），再按 Joint1→5、Gripper 顺序逐个上臂
4摄像头装臂（防呆口）→ 三路摄像头按顺序插电脑背面 → 串口线接拓展坞
5先接臂电源、后插 USB，跑第 05 节 find-port 找口并核对别名

③ 设置电机编号

给每个关节电机写入编号，编号是后续校准与遥操作映射的身份依据，不可跳过。

④ Gripper 夹爪装配

第 6 关节 gripper：夹爪舵机与弹簧组件的安装、对位与试合拢。

⑤ Joint1 · shoulder_pan

底座水平旋转关节：电机落座、同步带/齿轮对位，装好后底座应能平滑左右转。

⑥ Joint2 · shoulder_lift

肩俯仰关节：大臂起落的主受力关节，注意螺丝力矩与限位对齐。

⑦ Joint3 · elbow_flex

肘俯仰关节：小臂折叠的枢纽，装配后手动掰动应无卡滞。

⑧ Joint4 · wrist_flex

腕俯仰关节：控制手腕上下摆，零件细小，注意防呆与走线不夹线。

⑨ Joint5 · wrist_roll

腕滚转关节：最后一个旋转自由度，装完接夹爪即构成完整六关节手臂。

⚠ 装配纪律每装完一个关节，先手动全程掰一遍确认无卡滞再装下一个；发现卡滞立即拆检，别等通电了才发现——那时候你已经不知道是哪个关节装偏了。

05关键命令：搜索端口与核对别名

# ① 顺序：先将主从臂接通电源，再把 USB 插到电脑（顺序不要颠倒！）
conda activate lerobot

# ② 搜索端口（第 03 章）——列出当前所有端口后提示拔线
lerobot-find-port
Finding all available ports for the MotorsBus.
Ports before disconnecting: ['/dev/ttyACM0', '/dev/ttyACM2', '/dev/ttyACM3', '/dev/ttyACM1', …]
Remove the USB cable from your MotorsBus and press Enter when done.

# ③ 拔掉要找的那只臂的 USB → 回车，输出即为它的端口
The port of this MotorsBus is '/dev/ttyACM0'
Reconnect the USB cable.   # 插回继续找下一条（每次重启端口号可能会变化）

# ④ 查询串口信息，核对序列号与别名（示例为右主臂）
udevadm info --query=all --name=/dev/ttyACM0
S: arm_master_right
E: ID_SERIAL_SHORT=5B79018622
E: DEVLINKS=… /dev/arm_master_right …

# ⑤ 写入/检查四条别名规则（第 03 章 5）
sudo nano /etc/udev/rules.d/99-lerobot-arms.rules
#   5B61034506→arm_master_left   5B79018622→arm_master_right
#   5B79019324→arm_slave_left     5B79018452→arm_slave_right

# ⑥ 之后所有命令直接用稳定别名
#   /dev/arm_slave_left · /dev/arm_slave_right · /dev/arm_master_left · /dev/arm_master_right

08常见问题

  • find-port 找到的 ttyACM 比臂少一只：先查供电（主臂 5V 2A / 从臂 12V 8A 是否插对），再按"先断电→插 USB→再通电"顺序重插（第 03 章 1）
  • 重启后端口号对不上了：正常现象——"每次重启端口号可能会变化"，靠 udev 别名而不是 ttyACM 序号识别
  • udevadm info 查不到 arm_* 别名：规则文件没重载，或该臂序列号抄错一位
  • 摄像头线插了没画面：摄像头必须插电脑背面且按指导顺序插入；串口线才走拓展坞（第 02 章 4）
  • 某个关节方向装反/卡死：对照对应 Joint 视频重装，编号与机械限位一次对齐，别带病进 EXP-03
  • GPIO/串口权限报错：见 EXP-01 已加入 dialout 组；本课临时排查可用 sudo chmod 666 /dev/ttyACM*
💡 排障顺序先看灯与电源（硬件通电没）→ 再看线（左电源右串口对吗）→ 最后看软件（find-port 输出）。八成问题出在前两步。

09拓展挑战

🚀 挑战一：做一张"序列号—别名—插口"三联台账四条臂逐一 udevadm info 核对，把 ID_SERIAL_SHORT、SYMLINK 别名、实际插的拓展坞口位记成表；下次换机复现只看这张表。
🚀 挑战二：盲装一个关节在不看视频的情况下装配一个关节（如 Joint3），再回放视频核对螺丝顺序与走线，记录差异点——差异清单就是你的技能盲区清单。

10思考题

📝 思考题 1指导文档强调"先接通电源，再插 USB，顺序不要颠倒，可能导致连接失败"。结合 USB 枚举与供电时序，推演反着插时主机可能看到什么现象？你会用哪条命令验证猜测？
📝 思考题 2如果"设置电机编号"时把 Joint2 和 Joint3 的编号写反了，到 EXP-03 校准或 EXP-04 遥操作阶段会分别出现什么症状？为什么越早发现代价越小？
