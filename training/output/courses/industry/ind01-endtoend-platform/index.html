Learning Path

学习路径 · 32 学时怎么走

四个实验环环相扣：环境是地基，组装出实体，校准把双臂"对上表"，遥操作完成最终验收。

WEEK 1 · EXP-01

点亮平台

装驱动 → 装 conda → 装 LeRobot → 写 4 条机械臂 + 3 条相机 udev 规则，验证 /dev/arm_* 与 /dev/cam_* 全部就位。

WEEK 2 · EXP-02

组装双臂

主臂卡钳固定桌面、从臂连小推车，编号电机按 Joint1~5 + Gripper 上臂，接好 5V/12V 电源与串口线，find-port 落别名。

WEEK 3 · EXP-03

标定对表

三摄像头锁定插口，四臂逐一 calibrate：先 2047 中位基准，再全行程录 MIN/POS/MAX，写入 JSON 校准文件。

WEEK 4 · EXP-04

遥操作验收

单臂 60Hz、带摄像头 32Hz、双臂 12 关节跑通三档验收，会处置权限 / 缓存 / 卡死三类故障，读懂 0~9 号脚本。

实验学时核心交付验收标准
EXP-01 平台搭建8环境 + udev 规则全部生效ls /dev/arm_* 与 /dev/cam_* 列出 4 + 3 项
EXP-02 硬件组装8四臂装配完成、串口别名固定find-port 输出并核对 ID_SERIAL_SHORT
EXP-03 摄像头与校准8三路画面正确 + 4 份 JSONcalibrate 产出 MIN/POS/MAX 且误差可接受
EXP-04 遥操作排查8三档遥操作全通 + 故障处置60Hz / 32Hz 日志出现 NORM 关节表
◆ 学习提示每实验页都提供"关键命令"板块，所有命令与参数均摘自 LZ-XL01 指导文档原章节，直接复制到 conda activate lerobot 环境即可运行，不需要自己改编。
Assessment

考核建议

过程性考核为主，重在动手可复现：能装、能接、能校、能排障，才为后续端到端策略训练做好准备。

维度占比观测点
环境搭建完整性25%驱动 / conda / LeRobot / udev 四类配置齐全，验证命令输出正确
组装与串口识别25%四臂装配牢固、插接顺序正确、别名与序列号一一对应
校准质量25%2047 中位与 MIN/POS/MAX 录齐，左右臂差异在正常阈值内
遥操作与排障日志25%三档遥操作达标，能独立处置权限、缓存、卡死三类故障
！注意事项实验中若出现 PermissionError: [Errno 13]，先执行 sudo chmod 666 /dev/ttyACM*；录制阶段数据集名冲突要用新的 --dataset.repo_id 或清理对应缓存目录。
FAQ

常见疑问

问答
没有 LZ-XL01 实机能学吗？可以先通读四个实验页的原理、动画与命令板块建立完整心智模型，上机时对照操作；实机环节再补动手。
为什么每章要截图存到 images/？指导 PDF 里的终端输出与接线界面是排障时最常用的参照，随文插图便于对照真实现象。
视频为什么按实验分开？14 段指导视频按"装配 9 段 / 校准 3 段 / 遥操作 2 段"归到对应实验页，学到哪一步就看哪一段。
端到端的"端到端"指什么？指传感器感知到执行器动作之间不做人手拆解的中间模块；本课先把"端"（摄像头、机械臂）与"平台"打通。
