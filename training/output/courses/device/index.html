APP一体化工作台

推荐入口：一个页面搞定终端、文件、串口、桌面

工作台复用设备上同一个桥接服务：SSH 终端与文件管理共用一条登录会话，登录后即可浏览设备目录结构、 在线编辑文件并保存；串口与远程桌面也以标签页形式并存于同一界面。

⌨ SSH 终端

SETUP设备端准备

在设备上执行一次，之后开机即可用

网页端不需要安装任何东西。工作台所需的一切都在设备上的一个 Python 服务里，装好并设为开机自启即可。 若只用「本机 USB 直连」，本节可以直接跳过。

1把桥接服务与前端放到设备上

服务文件在课程仓库的 ros2_ws/fw/device_dev/device_bridge.py，把前端目录一起拷过去。

# 在开发机上执行，把 <设备IP> 换成实际地址
scp ros2_ws/fw/device_dev/device_bridge.py iflytek@<设备IP>:/home/iflytek/
scp -r training/output/courses/device iflytek@<设备IP>:/home/iflytek/bridge-web

2启动服务（依赖会自动安装）

首次运行会自动从清华源安装 aiohttp / paramiko / pyserial。串口默认值 /dev/ttyACM0 @115200 可按需修改。

ssh iflytek@<设备IP>
python3 device_bridge.py --port 8100 --static /home/iflytek/bridge-web \
  --serial-port /dev/ttyACM0 --baud 115200

3打开工作台并登录

回到本页点「启动工作台」，或直接在浏览器访问 http://<设备IP>:8100/。 填入设备上的 Linux 账号密码即可——桥接服务用这个账号登录设备自己的 sshd，密码不落盘、不回传。

备选方案：不装桥接服务，改用 ttyd / filebrowser / noVNC

A安装三个服务

Debian / Ubuntu 系设备，一条命令装齐（ttyd 承担终端入口）。

# 终端（ttyd）／桌面（websockify + noVNC）
sudo apt update
sudo apt install -y ttyd novnc websockify

# 文件管理（单个 Go 二进制，前端已内嵌）
curl -fsSL https://raw.githubusercontent.com/filebrowser/filebrowser/master/get.sh | bash

B启动服务

三个服务分别监听 7681 / 8081 / 6080，与上方「连接配置」里的默认端口一致。VNC 复用设备上已在运行的 VNC server（默认 5900）。串口始终走本机 USB 直连，无需设备端服务。

# 终端 —— 7681
ttyd -p 7681 -c admin:你的密码 -W bash

# 文件管理 —— 8081，根目录指向工作区
filebrowser -a 0.0.0.0 -p 8081 -r /home/iflytek -d /opt/device-dev/filebrowser.db

# 桌面 —— 6080，把本机 5900 的 VNC 转成 WebSocket
websockify --web=/usr/share/novnc 6080 127.0.0.1:5900

C把地址填到上方

回到本页「连接配置」，填入设备局域网 IP（如 192.168.1.100），点「检测连接」→ 三项状态变绿即表示服务已就绪。

🔒 桥接服务等同于把设备的 shell 与文件系统开放给能访问该端口的人（远程桌面另有 VNC 自己的密码保护）， 务必使用强密码，并只在教学网段内使用。完整安装说明、systemd 开机自启、防火墙与安全建议见 ros2_ws/fw/device_dev/README.md。
